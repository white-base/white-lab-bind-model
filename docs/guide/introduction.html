시작하기01

소개

비즈니스 로직과 화면을 분리하는 BindModel의 설계와 특징을 알아봅니다.

한국어 문서약 4분

BindModel은 React와 Vue 같은 현대적인 웹 프레임워크와 유연하게 연동되면서, 비즈니스 로직과 UI의 분리를 지원하는 독립적인 프레임워크입니다. SPA와 MPA 아키텍처를 모두 지원하며, 서버 측과 클라이언트 측에서 SSR과 CSR을 포함한 다양한 렌더링 방식을 제공합니다. 이를 통해 개발자는 비즈니스 로직의 재사용성을 극대화하고, 점진적인 개발을 통해 높은 생산성을 경험할 수 있습니다.

핵심 기능#

  • 비즈니스 로직의 분리 및 재사용성
    • 비즈니스 로직과 UI를 철저히 분리(MVC 패턴)
    • 동일한 비즈니스 로직을 여러 화면에서 재사용 가능
  • React 및 Vue 연동
    • Props Drilling 문제 해결
    • 다양한 프론트엔드 프레임워크와의 호환성 제공
  • 유연한 데이터 관리
    • MetaTable, MetaView 같은 엔티티를 통해 구조화된 데이터 처리 지원
    • 데이터 상태 변경 추적 및 중앙 집중식 데이터 관리 가능
    • 구조화된 데이터 처리 및 일반화를 지원하여 비즈니스 로직을 효과적으로 관리
  • 명령 기반 개발 패턴
    • 명령을 중심으로 비즈니스 로직을 구조화하고, 이를 일관된 방식으로 실행
    • 명령을 조합해 복잡한 비즈니스 로직을 효율적으로 처리

특징#

  • 독립적인 프레임워크
    • 특정 프레임워크에 종속되지 않으며 독립적으로 사용 가능
  • 유연한 개발 방식
    • 점진적 개발 방식을 지원해 초기 설계 없이도 프로젝트를 시작 가능
    • HTML 기반 개발에서 컴포넌트 기반 개발로 자연스럽게 확장 가능
  • 다양한 렌더링 방식 지원
    • SPA(React, Vue와의 연동) 및 MPA(Multi Page Application) 지원
    • 서버 사이드 렌더링(SSR)과 클라이언트 사이드 렌더링(CSR)을 모두 지원
  • 낮은 학습 곡선
    • 새로운 문법 지시자가 아닌 전통적인 개발 스타일 기반
    • 특정 프레임워크에 종속되지 않아 기존 지식으로 빠르게 적응 가능
  • 생산성과 유지보수성 강화
    • 재사용 가능한 비즈니스 로직과 엔티티 기반 구조로 코드를 간결하게 유지
    • 데이터와 UI의 분리로 복잡한 애플리케이션도 쉽게 유지보수 가능
  • 확장 및 통합 가능성
    • ES5와의 호환성을 통해 넓은 범용성 확보
    • 기존 프로젝트 또는 새로운 프로젝트에 쉽게 통합 가능
    • 단일 코드로 웹, Node.js 등 다양한 환경에서 작동 가능

BindModel은 데이터 중심 애플리케이션 개발을 효율적으로 지원하며, 복잡한 비즈니스 로직을 관리하고 재사용 가능한 코드를 작성하는 데 적합합니다.

기본 사용법#

BindModel은 화면 요소와 데이터를 연결하고, 서버와의 데이터 송수신을 단순화하는 기능을 제공합니다.

이 섹션에서는 서버에 데이터를 전송하거나, 서버에서 받은 데이터를 화면에 매핑하는 기본적인 사용 방법을 설명합니다.

1. 입력 요소 준비#

HTML에서 사용할 입력 요소를 정의합니다.

html
<input id="u_name" type="text" value="Neo" />

2. BindModel 객체 생성 및 컬럼 매핑#

JavaScript 코드에서 BindModel 객체를 생성한 후, 컬럼과 화면 요소를 연결합니다.

js
// BindModel 객체 생성
var bm = new BindModel();

// 셀렉터 값으로 'idx' 컬럼을 추가하고, 'cmd1' 명령의 매핑
bm.addSelector('u_name', '#u_name', 'cmd1');

3. 서버와 데이터 송수신#

command['cmd1'] 명령을 통해 서버로 데이터를 전송하거나, 서버로부터 데이터를 가져와 화면 요소에 자동으로 매핑할 수 있습니다.

서버로 데이터 전송#

js
bm.command['cmd1'].execute('SEND', '/user'); 

// 서버 경로 : /user
// 전송 데이터 : { "u_name": "Neo" }
  • 'item1'에 입력된 값을 서버로 전송합니다.

서버 응답 데이터 수신#

js
// 서버 경로 : /data/1
// 응답 데이터 : { "u_name": "Jane" }

bm.command['cmd1'].execute('VIEW', '/data/1');

bm.columns['item1'].value === 'Jane'; // true
  • 서버에서 데이터를 수신하여 'item1' 컬럼값에 설정합니다.

Tip 다음과 같이 별칭 속성을 사용할 수 있습니다: bm.cmd['cmd1'].exec('SEND', '/user'); bm.cmd['cmd1'].exec('VIEW', '/data/1');

기능 가이드02

컬럼 관리

컬럼을 만들고 화면 요소와 명령에 연결하는 방법을 알아봅니다.

한국어 문서약 27분

MetaColumn은 모델(BindModel)의 기본 구성 단위입니다.

컬럼은 다음 세가지 방식으로 추가할 수 있습니다:

  1. 모델(BindModel) 객체에서 추가
  2. 명령(BindCommand) 객체에서 추가
  3. 서비스객체에서 추가

셀렉터 속성으로 컬럼 추가#

모델(BindModel) 객체에 컬럼을 추가하고, 해당 컬럼에 selector 속성을 지정합니다.

ts
type KeyType = 'value' | 'text' | 'html' | 'attr.*' | 'prop.*' | 'css.*' | 'none';
type SelectorType = { key: string, type: KeyType };
type viewsType = 'valid' | 'bind' | 'output' | 'misc' | string /* 추가 뷰*/;

declare function addSelector(
	columnName: string, 
	selector: string | SelectorType, 
	cmds?: string | string[],
	views?: '$all' | viewsType | viewsType[], 
	bTable?: string | MetaTable
): void;
  • addSelector() : 컬럼 객체 또는 이름으로 컬럼을 추가 selector 객체를 설정합니다.
    • columnName : 추가할 컬럼명 입니다.
    • selector
      • string : selector 문자열을 지정합니다. ('value', 'text', 'html')
      • SelectorType : selector 객체를 지정합니다.
    • cmds : 명령(BindCommand) 이름을 지정합니다.
    • views : 참조를 등록할 뷰(MetaView) 이름을 지정합니다.
    • bTable : 컬럼이 등록될 테이블(MetaTable)을 지정합니다.

Tip selector에 문자열 키를 지정하면, 해당 DOM 요소를 검사하여 value, text, html 중 적절한 타입이 자동으로 지정됩니다. 이 외의 타입을 사용하려면, 객체를 통해 직접 지정해야 합니다.

컬럼 추가하기#

기본테이블(first)의 columns 컬렉션에 컬럼을 추가합니다.

js
const bm = new BindModel();

// 컬럼 추가 및 selector 초기값 설정
bm.addSelector('aa', '#u_id');
bm.addSelector('bb', { key: '#u_name', type: 'value'});

// bm.first.columns.count        === 2 (aa, bb)
// bm.columns.count              === 2 (aa, bb)
  • aa 컬럼 : 컬럼을 추가하고 #u_id selector 속성을 자동으로 지정합니다.
  • bb 컬럼 : 컬럼을 추가하고 #u_name selector 속성을 명시적으로 지정합니다.

Tip columns 속성은 first 테이블의 columns 컬렉션을 가르킵니다.

컬럼 추가 및 매핑하기#

기본 테이블(first)의 columns 컬렉션에 컬럼을 추가한 후, 지정한 명령(BindCommand)의 뷰(MetaView)에 참조를 등록합니다.

js
const bm = new BindModel();

// 컬럼 추가 및 selector 초기값 설정
bm.addSelector('cc', '#addr', 'read');
bm.addSelector('dd', '#tel', 'read', ['valid', 'bind']);

// bm.columns.count                    === 2 (cc, dd)
// bm.cmd['read'].valid.columns.count  === 2 (cc, dd)
// bm.cmd['read'].bind.columns.count   === 2 (cc, dd)
// bm.cmd['read'].output.columns.count === 1 (cc)
  • cc 컬럼 : #addr selector 로 컬럼을 추가하고, 'read' 명령의 모든 뷰에 참조를 등록합니다.
    • 모든 뷰 : valid, bind, output, misc
  • dd 컬럼 : #tel selector 로 컬럼을 추가하고, 'read' 명령의 bind, valid 뷰에 참조를 등록합니다.

모델에서 컬럼 추가#

모델(BindModel)객체에서 컬럼을 추가하고 초기값을 설정할 수 있습니다.

ts
type viewsType = 'valid' | 'bind' | 'output' | 'misc' | string /* 추가 뷰*/;

declare function addColumn(
    column: string | MetaColumn, 
    cmds?: '$all' | string | string[],
    views?: '$all' | viewsType | viewsType[], 
    bTable?: string | MetaTable
): BindCommand;

declare function addColumnValue(
    columnName: string, 
    value: string | number | boolean | { /* 컬럼속성 */ }, 
    cmds?: string | string[],
    views?: viewsType | viewsType[], 
    bTable?: string | MetaTable
): BindCommand;
  • addColumn() : 컬럼 객체 또는 이름으로 빈 컬럼을 추가합니다.
    • column : 추가할 컬럼 객체 또는 컬럼명 입니다.
    • cmds : 명령(BindCommand) 이름을 지정합니다.
    • views : 참조를 등록할 뷰(MetaView) 이름을 지정합니다.
    • bTable : 컬럼이 등록될 테이블(MetaTable)을 지정합니다.
  • addColumnValue() : 지정한 이름으로 컬럼을 추가하고 초기값을 설정합니다.
    • columnName : 추가할 컬럼명 입니다.
    • value : 컬럼의 초기값입니다.
    • cmds : 명령(BindCommand) 이름을 지정합니다.
    • views : 참조를 등록할 뷰(MetaView) 이름을 지정합니다.
    • bTable : 컬럼이 등록될 테이블(MetaTable)을 지정합니다.

Tip cmds 값으로 $all을 지정하면, 등록된 모든 명령(BindCommand)에 참조가 추가됩니다. views 값으로 $all 또는 undefined 지정하면 모든 뷰(valid, bind, output, misc)에 참조가 추가됩니다.

컬럼 추가하기#

기본테이블(first)의 columns 컬렉션에 컬럼을 추가합니다.

js
const bm = new BindModel();

// 'aa' 컬럼 추가
bm.addColumn('aa');           

// 'bb' 컬럼 추가 및 초기값 설정
bm.addColumnValue('bb', 10);  

// bm.first.columns.count  == 2
// bm.columns.count        == 2
// bm.columns['aa'].value  == ''
// bm.columns['bb'].value  == 10
  • addColumn(): 컬럼을 추가합니다.
  • addColumnValue(): 컬럼을 추가하고 초기값을 설정합니다.

Tip columns 속성은 first 테이블의 columns 컬렉션을 가르킵니다.

컬럼 추가 및 매핑하기#

기본 테이블(first)에 컬럼을 추가한 후, 지정한 명령(BindCommand)의 뷰(MetaView)에 참조를 등록합니다.

js
const bm = new BindModel();

// 'aa' 컬럼을 'cmd1'의 모든 뷰에 매핑
bm.addColumn('aa', 'cmd1');

// 'bb' 컬럼을 'cmd2', 'cmd3'의 'valid', 'bind'에 매핑
bm.addColumn('bb', ['cmd2', 'cmd3'], ['valid', 'bind']);

// 'cc' 컬럼을 모든 명령의 'output'에 매핑
bm.addColumn('cc', '$all', 'output');

// bm.columns.count  == 3 ('aa', 'bb', 'cc')

// bm.command['cmd1'].valid.columns.count  == 1 ('aa')
// bm.command['cmd1'].bind.columns.count   == 1 ('aa')
// bm.command['cmd1'].output.columns.count == 2 ('aa', 'cc')

// bm.command['cmd2'].valid.columns.count  == 1 ('bb')
// bm.command['cmd2'].bind.columns.count   == 1 ('bb')
// bm.command['cmd2'].output.columns.count == 1 ('cc')

// bm.command['cmd3'].valid.columns.count  == 1 ('bb')
// bm.command['cmd3'].bind.columns.count   == 1 ('bb')
// bm.command['cmd3'].output.columns.count == 1 ('cc')
  • aa 컬럼 : 빈 컬럼을 추가하고, 지정한('cmd1') 명령의 모든 뷰에 참조값을 매핑합니다.
  • bb 컬럼 : 빈 컬럼을 추가하고, 지정한('cmd1', 'cmd2') 명령의 특정('valid', 'bind') 뷰에 참조값을 매핑합니다.
  • cc 컬럼 : 빈 컬럼을 추가하고, 전체 명령의 특정('output') 뷰에 참조값을 매핑합니다.

Tip addColumnValue()를 사용하면 컬럼 추가와 초기값 설정을 동시에 수행하고 매핑할 수 있습니다.

명령에서 컬럼 추가#

명령(BindCommand) 객체에서 컬럼을 추가하거나 초기값을 설정할 수 있습니다.

ts
type viewsType = 'valid' | 'bind' | 'output' | 'misc' | string/* 사용자 정의 뷰 */;

declare function addColumn(
    column: string | MetaColumn, 
    views?: '$all' | viewsType | viewsType[], 
    bTable?: string | MetaTable
): BindCommand;

declare function addColumnValue(
    columnName: string, 
    value: string | number | boolean | { /*property*/ }, 
    views?: viewsType | viewsType[], 
    bTable?: string | MetaTable
): BindCommand;
  • addColumn() : 컬럼 객체 또는 이름으로 컬럼을 추가합니다.
    • column : 추가할 컬럼 객체 또는 컬럼명 입니다.
    • views : 참조를 등록할 뷰(MetaView) 이름를 지정합니다.
    • bTable : 컬럼의 등록되는 테이블(MetaTable)입니다.
  • addColumnValue() : 컬럼을 추가하고 초기값을 설정합니다.
    • columnName : 추가할 컬럼명 입니다.
    • value : 컬럼의 초기값입니다.
    • views : 참조를 등록할 뷰(MetaView) 이름를 지정합니다.
    • bTable : 컬럼의 등록되는 테이블(MetaTable)입니다.

Tip views에 '$all'을 지정하면, 모든 뷰(valid, bind, output, misc)에 참조가 추가됩니다.

컬럼 추가 및 매핑하기#

기본 테이블(first)에 컬럼을 추가하고, 대상 명령(BindCommand)의 뷰(MetaView)에 참조를 등록합니다.

js
const bm = new BindModel();

// 명령 추가
bm.addCommand('cmd1');

// 'aa' 컬럼을 'valid' 뷰에 매핑
bm.command['cmd1'].addColumn('aa', 'valid');

// 'bb' 컬럼을 'bind'와 'output' 뷰에 매핑
bm.command['cmd1'].addColumn('bb', ['bind', 'output']);

// 'cc' 컬럼을 모든 뷰에 매핑
bm.command['cmd1'].addColumn('cc', '$all');

// 'dd' 컬럼을 모든 뷰에 매핑
bm.command['cmd1'].addColumn('dd');

// bm.columns.count  == 4 ('aa', 'bb', 'cc', 'dd')

// bm.command['cmd1'].valid.columns.count  == 3 ('aa', 'cc', 'dd')
// bm.command['cmd1'].bind.columns.count   == 3 ('bb', 'cc', 'dd')
// bm.command['cmd1'].output.columns.count == 3 ('bb', 'cc', 'dd')
  • aa 컬럼 : 빈 컬럼을 추가하고, 지정한 명령의 특정 뷰('valid')에 참조값을 매핑합니다.
  • bb 컬럼 : 빈 컬럼을 추가하고, 지정한 명령의 특정 뷰('bind', 'output')에 참조값을 매핑합니다.
  • cc 컬럼 : 빈 컬럼을 추가하고, 지정한 명령의 전체 뷰에 참조값을 매핑합니다.
  • dd 컬럼 : 빈 컬럼을 추가하고, 지정한 명령의 전체 뷰에 참조값을 매핑합니다.

Tip '$all' 지시자는 명령의 모든 뷰(valid, bind, output, misc)와 함께, 사용자가 정의한 추가 출력 뷰까지 포함하여 참조합니다.

기존 컬럼 매핑하기#

이미 등록된 컬럼을 MetaView에 참조로 등록하거나 해제할 수 있습니다.

ts
type TableNameType = string;
type ColumnType = string;
type FullColumnType = `${TableNameType}.${ColumnType}`;
type ColumnDotType = FullColumnType | ColumnType;
type ViewType = 'valid' | 'bind' | 'output' | 'misc' | string /* 사용자 정의 뷰 */;

declare function setColumn(
    colName: ColumnDotType, 
    views: '$all' | ViewType | ViewType[], 
    bTable?: string | MetaTable
): void;

declare function release(
    colName: string, 
    views?: ViewType | ViewType[]
): void;
  • setColumn() : 기존에 등록된 컬럼을 지정한 뷰(MetaView)에 참조로 등록합니다.
  • release() : 지정한 뷰(MetaView)에 참조를 해제합니다.
    • 뷰를 지정하지 않으면, 해당 명령의 모든 뷰에서 컬럼이 해제됩니다.

이미 등록된 컬럼을 특정 뷰(MetaView)에 참조로 등록합니다.

js
const bm = new BindModel();

// 테이블 추가
bm.addTable('second');

// 기본 테이블(first)에 컬럼 추가
bm.addColumn('aa');
bm.addColumn('bb');

// 확장 테이블(second)에 컬럼 추가
bm['second'].columns.add('cc');
bm['second'].columns.add('dd');

// 명령 추가
bm.addCommand('test');

// 'aa'를 'valid' 뷰에 매핑
bm.command['test'].setColumn('aa', 'valid');             

// 'bb'와 second 테이블의 'cc'를 'bind' 뷰에 매핑
bm.command['test'].setColumn(['bb', 'second.cc'], 'bind'); 

// second 테이블의 'dd'를 모든 뷰에 매핑
bm.command['test'].setColumn('second.dd', '$all');       

// bm.first.columns.count  == 2 ('aa', 'bb')
// bm.second.columns.count == 2 ('cc', 'dd')

// bm.command['test'].valid.columns.count  == 2 ('aa', 'dd')
// bm.command['test'].bind.columns.count   == 2 ('bb', 'cc')
// bm.command['test'].output.columns.count == 2 ('cc', 'dd')
  • addTable() : 지정한 이름으로 MetaTable을 추가합니다.
  • columns.add() : 테이블에 컬럼을 추가합니다.

Tip 컬럼을 설정할 때는 테이블명 + . + 컬럼명 표기법을 사용하여 특정 테이블의 컬럼을 지정할 수 있습니다.

컬럼 해제하기#

release() 메서드를 사용하여 특정 뷰 또는 모든 뷰에서 컬럼 참조를 해제합니다.

js
// 'valid' 뷰에서 'aa' 컬럼 참조 해제
bm.command['test'].release('aa', 'valid');
// 'bind' 뷰에서 'bb'와 'cc' 컬럼 참조 해제
bm.command['test'].release(['bb', 'cc'], 'bind');
// 모든 뷰에서 'dd' 컬럼 참조 해제
bm.command['test'].release('dd', '$all');

// bm.command['test'].valid.columns.count == 0
// bm.command['test'].bind.columns.count == 0
// bm.command['test'].output.columns.count == 0
  • 컬럼을 해제할 때는 테이블명을 생략하고, 컬럼명만 지정하면 됩니다.

컬럼 및 명령 일괄 등록#

setMapping() 메서드는 컬럼과 명령별 역할(뷰)을 일괄 등록하는 기능을 제공합니다.

ts
type ColumnKey = string;  // 예: 'aa', 'first.bb', 'second.cc'
type CommandKey = string | '$all'; // 예: 'read', 'write', '$all'
type ViewEntry = 'valid' | 'bind' | 'output' | 'misc' | '$all';
type CommandMapping = Record<CommandKey, ViewEntry | ViewEntry[]> | {};
type MappingObject = Record<ColumnKey, CommandMapping>;

declare function setMapping(
	mapping: MappingObject, 
	bTable?: string | MetaTable
): void;
  • bTable : 매핑 시 컬럼 키에 테이블명이 생략된 경우 기본적으로 사용할 테이블을 지정합니다. (기본값: 'first')
js
const bm = new BindModel();          // 기본 생성

bm.setMapping({
	aa: {},
	bb: { cmd1: '$all' },  // 전체 뷰 매핑
	cc: { cmd2: ['valid', 'bind']  }
});

// bm.columns.count === 3  ('aa', 'bb', 'cc')
// bm.command['cmd1'].valid.columns.count === 1  ('bb')
// bm.command['cmd1'].bind.columns.count === 1   ('bb')
// bm.command['cmd1'].output.columns.count === 1 ('bb')

// bm.command['cmd2'].valid.columns.count === 1  ('cc')
// bm.command['cmd2'].bind.columns.count === 1   ('cc')
// bm.command['cmd2'].output.columns.count === 0

컬럼 키에 테이블명 + '.' + 컬럼명 형식을 사용하면, 컬럼은 기본 테이블이 아닌 해당 테이블에 등록됩니다.

js
const bm = new BindModel();          // 기본 생성

bm.setMapping({
	'aa': {},
	'first.bb': { cmd1: '$all' },  // 전체 뷰 매핑
	'second.cc':  { cmd2: ['valid', 'bind']  }
});

// bm.columns.count === 2  ('aa', 'bb')
// bm.first.columns.count === 2  ('aa', 'bb')
// bm.second.columns.count === 1  ('cc')

// bm.command['cmd1'].valid.columns.count === 1  ('bb')
// bm.command['cmd1'].bind.columns.count === 1   ('bb')
// bm.command['cmd1'].output.columns.count === 1 ('bb')

// bm.command['cmd2'].valid.columns.count === 1  ('cc')
// bm.command['cmd2'].bind.columns.count === 1   ('cc')
// bm.command['cmd2'].output.columns.count === 0
  • columns 속성은 first.columns 컬렉션의 참조 속성입니다.

컬럼 주요 속성#

HTMLColumn은 모델(BindModel)에서 사용되며, MetaColumn을 상속하여 확장된 구성 요소입니다.

항목 타입 설명
value string | number | boolean 컬럼의 현재 값을 나타냅니다.
default string | number | boolean 컬럼의 기본 값을 설정합니다.
getter () => any value 값을 가져오는 getter 함수입니다.
setter (val: any) => void value 값을 설정하는 setter 함수입니다.
getFilter (val: any) => any value 값을 가져올 때 적용되는 filter 함수입니다.
setFilter (val: any) => any value 값을 설정할 때 적용되는 filter 함수입니다.
selector { key: string, type: string} 셀렉터를 정의합니다.
required boolean 필수 여부를 설정합니다.
constraints {regex: RegExp, msg: string} <br>(val: any) => boolean 컬럼의 제약 조건을 정의합니다.(복수 제약조건)
columnName string 컬럼의 이름을 나타냅니다.
alias string 컬럼의 별칭을 나타냅니다.
caption string 컬럼에 대한 설명을 제공합니다.

컬럼값(value)#

컬럼 값(value)을 조회하거나 설정할 때는 다음과 같은 속성을 활용하여 다양한 처리를 수행할 수 있습니다.

  • default, getter, setter, getFilter, setFilter, selector

참조 : 컬럼값 호출 구조 #참조

제약 조건#

MetaColumn에 제약조건은 required와 constraints 속성을 통해 value 값을 검사할 수 있습니다.

ts
type ConstraintType = { regex: RegExp, msg: string, match: boolean };
type FunctionType = (value: any) => boolean ;
type complexType = ConstraintType | FunctionType;

type constraints = complexType[] | complexType;
  • required : 필수값 여부를 지정합니다.
    • true로 설정하면 필수값으로 지정되며, 기본값은 false입니다.
  • constraints : 함수 또는 객체 타입으로 설정하여 제약 조건을 지정합니다.
    • regex : 정규 표현식
    • msg : 검사 실패 시 출력할 메시지
    • match : 매칭 방식 false로 설정하면 비매칭 조건으로 처리됩니다. (기본값: true)

제약조건 사용 빈도#

컬럼의 특성에 따라 조건을 혼합하여 구성할 수 있습니다. 기본값은 선택 조건입니다.

사용빈도 required constraints 설명
50% 선택값입니다.
30% true 필수값입니다.
15% {…} | Function 선택값이며, value 에 제약조건이 있습니다.
5% true {…} | Function 필수값이며, value 에 제약조건이 있습니다.

필수 조건#

컬럼 추가 시 초기값으로 required 속성을 설정합니다.

js
bm.addColumnValue('u_code', { 
	required: true 
});
  • 필수 조건으로 설정되며, 공백일 경우 실패 처리되고 cbFail 콜백 함수가 호출됩니다.

매칭 제약 조건#

컬럼 추가 시 초기값으로 constraints 속성에 매칭할 정규식을 설정합니다.

js
bm.addColumnValue('u_code', { 
	constraints: { 
		regex: /[a-zA-Z0-9]{6,}/, 
		msg: "Please enter at least 6 chars."
	}
});
  • 값이 없으면 통과되며, 값이 있을 경우 사용자 정의 함수가 true를 반환해야 조건을 만족합니다.
    • required의 기본값은 false이며, 이는 선택 입력 조건을 의미합니다.

비매칭 제약 조건#

컬럼 추가 시 초기값으로 constraints 속성에 비매칭 조건과 match 값을 false 로 설정합니다

js
bm.addColumnValue('u_code', { 
	constraints: { regex: /[0-9]/, msg: "No numbers", match: false }
});
  • 선택 조건으로 동작하며, 값이 공백일 경우 유효성 검사를 통과합니다. 단, 값이 입력된 경우에는 지정된 정규식과 매칭되지 않아야 통과됩니다.

사용자 함수 제약 조건#

컬럼 추가 시 초기값으로 constraints 속성에 사용자 정의 함수를 설정합니다.

js
bm.addColumnValue('u_code', { 
	constraints: (val) => { return val.length > 8 }
});
  • 선택 조건으로 설정되며, 값이 공백일 경우 유효성 검사를 통과합니다. 그러나 값이 입력된 경우에는, 사용자 정의 함수가 true를 반환해야 유효성 검사를 통과합니다.

혼합 제약 조건#

컬럼 추가 시 초기값으로 constraints 속성에 배열로 사용자 정의 함수와 정규식을 설정합니다.

js
bm.addColumnValue('u_code', { 
	constraints: [
		{ regex: /# .{6}$/, msg: "Minimum 6 characters required" },
		{ regex: /[0-9]/, msg: "Numbers are not allowed", match: false },
		(val) => { return val.length >= 8 }  // // Must be at least 8 characters
	],
	required: true
});
  • 필수 조건으로 설정되며, 숫자를 제외한 문자의 길이가 6 이상 8 이하일 경우 유효성 검사를 통과합니다.

Tip 복수의 constraints를 설정하려면 배열로 추가할 수 있으며, 모든 조건이 충족되어야 성공으로 간주됩니다. 기존 constraints에 조건을 추가하려면 addConstraint() 메서드를 사용하세요.

별칭(alias)#

별칭은 서버로 데이터를 전송하거나 서버에서 데이터를 받을 때 컬럼명과 데이터 키를 매칭하는 데 사용됩니다.

제약조건 별칭 이름은 기존의 컬럼명이나 다른 별칭과 중복될 수 없습니다.

데이터를 전송할 경우#

서버로 데이터를 전송할 때 별칭이 설정된 컬럼은 별칭 이름으로 전송됩니다.

js
const bm = new BindModel();

// 'create' 명령 추가
bm.addCommand('create');

// 'aa', 'bb' 컬럼 추가
bm.command['create'].addColumnValue('aa', 10);
bm.command['create'].addColumnValue('bb', 20);

// 'AA' 별칭 설정
bm.columns['aa'].alias = 'AA';

// 'create' 명령 실행
bm.cmd['create'].execute('SEND', '/user');
json
// SEND DATA
{ "AA": 10, "bb": 20 }
  • 'aa' 컬럼은 전송시 'AA' 이름으로 전송됩니다.

데이터를 가져올 경우#

서버에서 데이터를 받을 때, 별칭을 기준으로 로우 데이터를 컬럼명과 매칭합니다.

json
// SERVER DATA
{ "AA": 10, "bb": 20, "cc": 30 }
js
const bm = new BindModel();

// 'list' 명령 추가
bm.addCommand('list', 'VIEW');

// 'list' 명령의 서버 경로 설정
bm.command['list'].url =  '/user';

// 'aa', 'bb' 컬럼 추가
bm.command['list'].addColumnValue('aa', 10);
bm.command['list'].addColumnValue('bb', 20);

// 별칭 설정
bm.columns['aa'].alias = 'AA';

// 'list' 명령 실행
bm.cmd['list'].execute();

// bm.columns['aa'].value == 10
// bm.columns['bb'].value == 20
// bm.cmd['list'].output.rows[0]['AA'] == 10
// bm.cmd['list'].output.rows[0]['bb'] == 20
  • 서버 응답 데이터 중 'AA'라는 이름의 항목은, 내부적으로 'aa' 컬럼에 값으로 설정됩니다.

Tip MetaRow 객체 내부에서 별칭은 속성값으로 참조됩니다.

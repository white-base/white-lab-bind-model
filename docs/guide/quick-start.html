시작하기01

빠른 시작

설치부터 첫 데이터 바인딩까지, 작은 예제로 시작해 보세요.

한국어 문서약 8분
예제 기준: logic-bind-model 1.1.13

Node.js에서는 npm 패키지를, 브라우저에서는 아래 CDN 파일을 사용하세요. 서버 요청 예제의 /user는 직접 준비한 API 주소로 바꿔 주세요.

BindModel 이란?#

BindModel은 비즈니스 로직과 UI를 분리하여 재사용성과 유지보수를 극대화한 독립적인 웹 프레임워크입니다. React, Vue와 같은 SPA부터 MPA 및 SSR 환경까지 유연하게 지원하며, 구조화된 데이터 처리와 명령 기반 개발 패턴으로 생산성과 확장성을 제공합니다. HTML 기반의 전통적인 개발 스타일을 유지하면서도 최신 TypeScript와 ES5 호환성을 동시에 갖춘 범용 솔루션입니다.

설치하기#

node 환경#

bash
npm install logic-bind-model

브라우저 환경#

html
<script src="https://unpkg.com/logic-bind-model@1.1.13/dist/bind-model.js"></script>

node 환경에서 사용하기#

CommonJS 환경#

require 구문을 사용하여 모듈을 가져옵니다.

js
const { BindModel } = require('logic-bind-model');

const bm = new BindModel();

Tip MetaTable, MetaView, HTMLColumn 등 다양한 클래스를 가져올 수 있습니다.

ESM 환경#

import 구문을 사용하여 모듈을 가져옵니다.

js
import { BindModel } from 'logic-bind-model';

const bm = new BindModel();

Typescript 환경#

TypeScript에서도 import 구문을 동일하게 사용합니다.

ts
import { BindModel } from 'logic-bind-model';

const bm: BindModel = new BindModel();

Tip 모듈 경로에 logic-bind-model/ko를 지정하면 한글 타입 정보를 사용할 수 있습니다. 이는 다국어 타입 지원을 위한 준비 기능이며, 추후 다음 언어들이 순차적으로 지원될 예정입니다: 'ja', 'zh', 'hi', 'es', 'pt', 'ru', 'fr', 'de'

브라우저 환경에서 사용하기#

ESM 환경#

브라우저에서 모듈 형식으로 사용하려면 type="module" 속성을 사용합니다.

html
<script type="module" >
  import { BindModel } from 'https://unpkg.com/logic-bind-model@1.1.13/dist/bind-model.esm.js';
  const bm = new BindModel();
</script>

Tip 위 경로의 JS 파일을 프로젝트 내에 복사한 후, 로컬 경로로도 불러올 수 있습니다.

레거시 환경 (비모듈 브라우저)#

레거시 환경에서는 전역 객체 _L을 통해 접근합니다.

html
<script src="https://unpkg.com/logic-bind-model@1.1.13/dist/bind-model.js"></script>
<script>
  var BindModel = _L.BindModel;
  var bm = new BindModel();
</script>

Tip _L 전역 변수로 MetaTable, MetaView, HTMLColumn 등 다양한 클래스에 접근할 수 있습니다.

예제 소스#

이 예제는 웹 애플리케이션에서 서버로부터 회원 정보를 조회하여 화면에 표시하는 기본적인 구현 사례입니다.

서버 응답 예시#

json
{ "u_code": 1234, "u_name": "Neo" }

HTML 구조#

html
<h2 id="u_code"></h2>
<input id="u_name" type="text"/>

JavaScript 구성#

BindModel은 사용 목적에 따라 다양한 방식으로 구성할 수 있습니다. 아래는 세 가지 패턴을 소개합니다.

간단하게 구성하기#

가장 간단한 방법으로, 컬럼을 selector 형식으로 등록하고, 명령 실행시 경로와 타입을 지정합니다.

js
// BindModel 객체 생성
const bm = new BindModel();

// 컬럼을 selector 형식으로 등록하고, 'cmd1' 명령의 'output' 뷰에 매핑
bm.addSelector('u_code', '#u_code', 'cmd1', 'output');
bm.addSelector('u_name', '#u_name', 'cmd1', 'output');

// 'cmd1' 명령 실행: 서버에서 데이터를 조회하여 화면에 매핑
bm.command['cmd1'].execute('VIEW', '/user');

// 결과
// bm.columns['u_code'].value == 1234
// bm.columns['u_name'].value == 'Neo'
  • 'cmd1'은 명령 이름이고, 'output'은 해당 명령의 출력 뷰 이름입니다.
  • 명령 옵션 : 'SEND', 'VIEW', 'ALL', 'PICK'
  • 뷰 종류: valid, bind, output, misc

단계별로 구성하기#

각 단계를 명확히 분리하여 명령, 컬럼, 셀렉터를 순차적으로 설정합니다.

js
// BindModel 객체 생성
const bm = new BindModel();

// 서버 URL 설정
bm.url = '/user';

// 'cmd1' 명령 추가 ('VIEW'는 출력 옵션)
bm.addCommand('cmd1', 'VIEW');

// 컬럼 등록 및 뷰 연결
bm.addColumn('u_code', 'cmd1', 'output');
bm.addColumn('u_name', 'cmd1', 'output');

// 컬럼에 화면 요소(셀렉터) 연결
bm.columns['u_code'].selector = { key: '#u_code', type: 'text' };
bm.columns['u_name'].selector = { key: '#u_name', type: 'value' };

// 명령 실행
bm.command['cmd1'].execute();

// 결과
// bm.columns['u_code'].value == 1234
// bm.columns['u_name'].value == 'Neo'
  • 'VIEW' 옵션은 서버 응답에서 지정한 뷰(예: 'output')의 첫 번째 데이터(rows)를 컬럼에 할당합니다.

서비스객체로 구성#

서비스 객체를 통해 모델 구성을 한 번에 정의할 수 있습니다.

js
const bm = new BindModel({

	// 서버 URL 설정
	url: '/user',
	
	// 컬럼 및 셀렉터 정의
	items: {
		u_code: { selector: { key: '#u_code', type: 'text' } },
		u_name: { selector: { key: '#u_name', type: 'value' } }
	},
	
	// 명령 정의
	command: {
		cmd1: { outputOption: 'VIEW' }
	},
	
	// 매핑 설정: 명령 'cmd1'의 'output' 뷰에 컬럼 매핑
	mapping: {
		u_code: { cmd1: ['output'] },
		u_name: { cmd1: ['output'] }
	}
});

// 명령 실행
bm.command['cmd1'].execute();

// 결과
// bm.columns['u_code'].value == 1234
// bm.columns['u_name'].value == 'Neo'

Tip 서비스 객체 방식은 구성 정보를 분리하여 관리할 수 있어, 코드의 재사용성과 유지보수성을 크게 향상시킵니다.

핵심 개념

모델, 명령, 테이블과 뷰. BindModel을 구성하는 기본 개념을 살펴봅니다.

한국어 문서약 12분

핵심 개념을 숙지하면 BindModel을 보다 자유롭게 제어할 수 있습니다.

MetaTable 의 이해#

MetaTable은 데이터를 컬럼(column)과 행(row)으로 구성하는 객체입니다.

• 컬럼 : 데이터를 정의하는 columns 컬렉션 • 행 : 데이터를 저장하는 rows 컬렉션

MetaTable은 .NET의 DataTable과 유사한 구조를 가지고 있어, 이에 익숙하다면 쉽게 사용할 수 있습니다.

MetaTable 클래스 생성자

ts
declare class MetaTable {
	constructor(tableName: string);
}
js
import { MetaTable } from 'logic-bind-model';

const table = new MetaTable('테이블명');

table.columns.add('name');     // 'name' 컬럼 추가
table.columns.add('age');      // 'age' 컬럼 추가

let row = new table.newRow();  // 새로운 행 생성

row['name'] = 'Neo';           // 'name' 컬럼에 값 할당
row['age'] = 20;               // 'age' 컬럼에 값 할당
table.rows.add(row);           // 행을 rows 컬렉션에 추가

// table.rows[0]['name']  === 'Neo'
// table.rows[0]['age']   === 20
// table.rows.count       === 1
// table.columns.count    === 2
  • columns.add(columnName) : columns 컬렉션에 컬럼을 추가합니다.
  • newRow() : 컬럼 스키마에 기반한 새로운 MetaRow 객체를 생성합니다.
  • rows.add(row) : 생성된 MetaRow 객체를 rows 컬렉션에 추가합니다.

Tip columns의 단축형인 'cols'를 사용할 수 있습니다.

컬럼의 현재값과 데이터 구성#

MetaTable의 컬럼값은 현재값을 나타내며, rows는 이러한 컬럼값들의 집합으로 구성됩니다.

js
import { MetaTable } from 'logic-bind-model';

const table = new MetaTable('테이블명');

table.columns.add('age');         // 'age' 컬럼 추가
table.columns['age'].value = 10;  // 'age' 컬럼의 값 설정

let row = new table.newRow();     // 새로운 행 생성
row['age'] = 20;                  // 행에 데이터 추가
table.rows.add(row);              // 행을 rows 컬렉션에 추가

// table.columns['age'].value  === 10 (현재 컬럼값)
// table.rows[0]['age']        === 20 (첫번째 행의 값)

Tip columns.addValue(컬럼명, 컬럼값)을 사용하여 컬럼 등록과 초기 값을 동시에 설정할 수 있습니다.

초기값 설정 및 데이터 추가#

컬럼값은 MetaRow 타입으로 얻을 수 있으며, MetaRow 타입은 컬럼값(value)으로 지정할 수 있습니다.

js
import { MetaTable } from 'logic-bind-model';

const table = new MetaTable('테이블명');

table.columns.add('age');         // 'age' 컬럼 추가
table.columns['age'].value = 10;  // 현재값 설정

let row = table.getValue();       // 현재값 기반 MetaRow 생성
table.rows.add(row);              // 행 추가

// table.columns['age'].value === 10 (현재 컬럼값)
// table.rows[0]['age']       === 10 (첫번째 행의 값)

table.rows[0]['age'] = 20;        // 첫 번째 행 값 수정
table.setValue(table.rows[0]);       // 수정된 행을 컬럼의 현재값으로 설정

// table.columns['age'].value === 20 (업데이트된 컬럼값)
  • getValue() : 컬럼의 현재값으로 구성된 MetaRow 객체를 반환합니다.
  • setValue(row) : 주어진 MetaRow 객체를 컬럼의 현재(value)값으로 설정합니다.

제약조건 MetaTable의 rows 컬렉션에 데이터를 추가한 이후에는 columns 컬렉션에 새로운 컬럼을 추가하거나 기존 컬럼을 제거할 수 없습니다. 이는 데이터의 일관성을 유지하기 위한 제약입니다.

MetaView 의 이해#

MetaView는 MetaTable과 유사하지만, 중요한 차이점이 있습니다.

MetaView는 columns 컬렉션에 컬럼의 참조값을 등록할 수 있습니다. 이를 통해 원본 컬럼을 공유하거나, 필요에 따라 독립적으로 처리할 수 있습니다.

Tip MetaTable에 컬럼을 추가하면 해당 컬럼은 항상 독립적으로 구성됩니다. 반면, MetaView는 참조 컬럼을 활용하여 원본 컬럼을 공유할 수도 있습니다.

모든 컬럼을 참조로 등록#

MetaView를 생성할 때 baseEntity를 지정하면, 해당 객체(MetaTable 또는 MetaView)의 컬럼들이 MetaView에 참조값으로 등록됩니다.

만약 baseEntity를 지정하지 않으면 MetaTable과 동일한 방식으로 작동합니다.

MetaView 클래스 정의

ts
declare class MetaView {
	constructor(name: string, baseEntity?: MetaView | MetaTable);
}

Tip baseEntity는 MetaTable 또는 MetaView 타입만 지정할 수 있습니다. 만약 MetaView를 지정하면 순환 규칙에 따라 원본 컬럼에 참조합니다.

js
import { MetaTable, MetaView } from 'logic-bind-model';

const table = new MetaTabe('t1');
const view = new MetaView('v1', table);  // 'baseEntity' 속성을 't1'으로 설정

view.columns.add('age');       // 'age' 컬럼 추가
view.columns.add('gender');    // 'gender' 컬럼 추가

// table.colmmns.count === 2
// view.colmmns.count  === 2

// view.columns['age']    === table.columns['age']
// view.columns['gender'] === table.columns['gender']
  • view1.columns['age']는 table1.columns['age']의 참조값입니다.

Tip MetaView 생성 이후에도 _baseEntity를 설정할 수 있습니다. 이 경우, 이후에 추가되는 컬럼부터 참조가 적용됩니다.

특정 컬럼만 참조로 등록#

특정 컬럼만 참조로 등록하려면, 컬럼을 추가할 때 대상 컬렉션을 명시적으로 지정해야 합니다.

함수 정의

ts
declare function add(
	columnName: string, 
	refCollection?: MetaViewColumnCollection
): number;
js
import { MetaTable, MetaView } from 'logic-bind-model';

const table = new MetaTabe('t1');
const view = new MetaView('v1');

view.columns.add('age');                     // 'view'에 독립 컬럼 추가
view.columns.add('gender', table1.columns);  // 't1'의 컬럼 참조 추가

// table.colmmns.count === 1
// view.colmmns.count === 2

// view.columns['gender'] === table.columns['gender']
  • 컬럼 추가시 기존에 등록된 컬럼을 지정하여 참조로 등록할 수 있습니다.
    • views.columns.add(table.columns['memo'])

Tip 특정 컬렉션을 지정하여 컬럼을 추가하면, 지정된 컬렉션에 컬럼이 추가되고, 해당 컬럼의 참조값이 MetaView에 등록됩니다.

이렇게 테이블과 뷰의 조합을 통해서 다양한 구조를 구현할 수 있습니다.

BindModel 구조의 이해#

BindModel 객체는 기본으로 MetaTable(first)을 포함하며, 명령(BindCommand)을 추가할 수 있습니다. 각각의 명령은 MetaTable(first)을 참조하는 MetaView(valid, bind, output)로 구성됩니다.

js
import { BindModel } from 'logic-bind-model';

const bm = new BindModel();

bm.addCommand('cmd1');      // 'cmd1' 명령 추가

// bm.first                  : MetaTable
// bm.command['cmd1']        : BindCommand
// bm.command['cmd1'].valid  : MetaView
// bm.command['cmd1'].bind   : MetaView
// bm.command['cmd1'].output : MetaView

모델(BindModel)에 추가된 명령(BindCommand)의 뷰(valid, bind, output)는 _baseEntity 에서 지정한 MetaTable을 참조합니다.

동일한 이름의 컬럼을 사용하거나 독립된 컬럼을 사용하려면, 테이블을 추가하여 컬럼을 지정할 수 있습니다.

Tip 명령에 따라 별도의 테이블을 생성하고 컬럼을 독립적으로 관리하면 데이터 구조를 더욱 체계적으로 설계할 수 있습니다.

5-1단계 : 명령(list) 서비스 객체 구성#

조회된 데이트를 확인 가능하게 목록 명령에 대한 명칭을 list 로 지정하고 서비스 객체를 구상합니다.

items 서비스 객체 구성#

아이템 대상이 되는 항목을 정의합니다.

  • 서버로 전송하거나 받을 항목
  • 제어가 필요한 위치를 아이템으로 구성합니다.

각 항목은

  • _area_temp 은 목록을 handlebars 템플릿을 사용할 양식입니다.
    • <script id="area-temp" type="text/x-handlebars-template">
  • _area_tbody 템플릿으로 생성된 코드를 추가할 위치를 가르킵니다.
    • <tbody id="area-tbody">
  • _area_form 은 읽기/수정/등록에 사용할 폼 양식들이 있는 영역을 가르킵니다.
  • _area_btn_edit 은 읽기/수정에 사용할 버튼(update, deate, list) 영역을 가르킵니다.
  • _area_btn_create 은 신규 등록에 사용할 버튼(reset, save, cacel) 영역을 가르킵니다.
  • _area_btn_form 은 신규 등록시 폼양식 을 보이게 하는 버튼이 구성된 영역을 가르킵니다.

selector 속성의 key 는 셀렉터 값을 의미하고 type 셀렉터에 대한 타입을 지정합니다.

  • type='html' 는 html 태그를 가르킵니다.
  • type='attr.*' 는 지정한 요소의 정적 속성에 대한 값을 가르킵니다.
    • type='attr.class' 지정한 요소의 <div class='d-none'> 값
    • 부트스트립트에 d-none 값은 style="display:none;" 와 같은 기능입니다.
js
this.items = {
  _area_temp: { selector: { key: `#area-temp${_SUFF}`, type: 'html' } },
  _area_tbody: { selector: { key: `#area-tbody${_SUFF}`, type: 'html' } },
  _area_form: { selector: { key: `#class-form${_SUFF}`, type: 'attr.class' } },
  _area_btn_edit: { selector: { key: `#edit-button${_SUFF}`, type: 'attr.class' } },
  _area_btn_create: { selector: { key: `#create-button${_SUFF}`, type: 'attr.class' } },
  _area_btn_form: { selector: { key: `#form-button${_SUFF}`, type: 'attr.class' } },
};

fn 서비스 객체 구성#

목록에서 내용을 선택하면 처리할 기능을 fn 영역에 추가합니다.

js
this.fn = {
  procRead(index) {
	_this.bindModel.items._index = index;
	_this.bindModel.command['read'].execute();
  },
};

command 서비스 객체 구성#

서버 경로에서 모든 데이터를 가져오기 위해서 outputOption: 'ALL' 로 지정하였습니다. (기본값은 'SEND' 서버에 데이터를 전송 후 데이터는 받지 않습니다.)

처음으로 실행되는 cbBegin 콜백함수에 폼영역은 숨기고, 신규 등록시 폼양식은 보이도록 설정합니다.

cbOutput 콜백함수에 서버에서 전송받은 데이터를 MetaView 에 저장이후에, 화면 출력과 관련된 부분을 정의합니다.

  • Handlebars 템플릿에 translateActive 헬퍼를 등록합니다. (코드를 값으로 변환)
  • _template 템플릿 양식을 컴파일하여 템플릿 객체를 생성합니다.
  • _template(outs[0].rows) 템플릿 객체에 데이터를 전달하여, 파싱 결과를 _area_tbody 에 붙임
    • outs 인자는 출력뷰의 컬렉션을 가르키면 outs[0].rows 는 첫번째 MetaView 을 rows 데이터를 가르킵니다.
  • 목록에 대한 이벤트를 등록합니다.
    • document.getElementById('area-tbody').addEventListener('click', ...)
js
this.command = {
  list: {
	outputOption: 'ALL',
	
	cbBegin(model, cmd) {
	  model.columns['_area_form'].value = 'd-none';
	  model.columns['_area_button'].value = '';
	},
	
	cbOutput(outs, cmd, res) {
	  Handlebars.registerHelper('translateActive', function (code) {
		if (code === 'S') return 'Standby';
		if (code === 'A') return 'Activation';
		if (code === 'H') return 'hidden';
		return '';
	  });
	  if (_template === null) {
		_template = Handlebars.compile( _this.bindModel.columns['_area_temp'].value );
	  }
	  _this.bindModel.columns['_area_tbody'].value = _template(outs[0].rows);
	
	  document.getElementById('area-tbody').addEventListener('click', function (e) {
		const target = e.target.closest('.btnNormal');
		if (target && target.dataset.index) {
		  const index = parseInt(target.dataset.index, 10);
		  if (!isNaN(index)) cmd._model.fn.procRead(index);
		}
	  });
	}
  }
};

목록 템플릿 양식으로 본문에 추가합니다.

{{#each this}} 블럭은 배열갯수 만큼 반복하여 파싱합니다.

html
<script id="area-temp" type="text/x-handlebars-template">
{{#each this}}
  <tr>
	<td><a href="#" class="btnNormal" data-index="{{@index}}">{{title}}</a></td>
	<td>{{translateActive active_cd}}</td>
	<td>{{create_dt}}</td>
  </tr>
{{/each}}
</script>

mapping 서비스 객체 구성#

items 에서 정의한 아이템을 별도의 뷰(misc) 에 지정합니다. misc 는 서버에 전송과 수신과정에 관여하지 않습니다. 단지 매핑을 위해 임시로 지정한 뷰입니다.

각각 아이템에 대한 'list' 명령의 'misc' 뷰에 매핑입니다.

js
this.mapping = {
  _area_temp: { list: 'misc' },
  _area_tbody: { list: 'misc' },
  _area_form: { list: 'misc' },
  _area_btn_edit: { list: 'misc' },
  _area_btn_create: { list: 'misc' },
  _area_btn_form: { list: 'misc' },
};

main.js 실행 및 테스트#

초기에 실행할 명령(list) 을 지정하고, 결과를 확인합니다.

items 서비스 객체 구성#

아이템 대상이 되는 항목을 정의합니다.

  • 서버로 전송하거나 받을 항목
  • 제어가 필요한 위치를 아이템으로 구성합니다.

각 아이템

  • ntc_idx 는 hidden 값으로 지정합니다.
  • title 은 필수 조건으로 지정합니다. (required = true)
  • top_yn, active_cd 은 setFilter, getFilter 를 설정하여 지정합니다.

Tip 아니의 아이템이 복수의 요소를 제어하거나, 실제 값과 표현되는 값이 다를 경우 getFilter, setFilter 를 활용합니다.

js
this.items = {
  ntc_idx: { selector: { key: `#ntc_idx${_SUFF}`, type: 'value' } },
  title: {
	selector: { key: `#title${_SUFF}`, type: 'value' },
	required: true,
  },
  contents: { selector: { key: `#contents${_SUFF}`, type: 'value' } },
  top_yn: {
	selector: { key: `input[name=top_yn${_SUFF}]`, type: 'none' },
	setFilter(val) {
	  $(`input[name=top_yn${_SUFF}]`).prop('checked', val == 'Y' ? true : false);
    },
	getFilter(val) {
	  return $(`input[name=top_yn${_SUFF}]:checked`).val() || 'N';
	}
  },
  active_cd: {
	selector: { key: `input[name=active_cd${_SUFF}][type=radio]`, type: 'none' },
	setFilter(val) {
	  $(`input[name=active_cd${_SUFF}][value=${val}]`).prop('checked', true);
	},
	getFilter(val) {
	  return $(`input[name=active_cd${_SUFF}]:checked`).val();
	}
  }
};

command 서비스 객체 구성#

cbEnd 콜백함수를 설정하여 등록 완료 후에 사용자에게 메세지를 표시합니다.

_this 객체는 서비스 클래스 정의시 자신을 가르키는 속성입니다.

cmd 인자를 사용하여 cmd._model.cmd['list'].execute() 으로 지정할 수도 있습니다.

js
this.command = {
  create: {
	cbEnd(status, cmd, res) {
	  if (res) {
		alert('The post has been created.');
		_this.bindModel.cmd['list'].execute();
	  }
	}
  },
};

등록 버튼을 선택시 폼을 초기화 하고, 폼양식을 화면에 보여줌니다.

this.fn = {

  }
};

5-3 단계 : 명령(read) 서비스 객체 구성#

지정한 서버 데이터를 각 폼 요소에 가져옵니다.

items 서비스 객체 구성#

_index 는 정적 JSON 을 샘플로 가져오므로 임시로 데이터를 가져오는데 활용하였습니다.

등록일 아이템 create_dt 을 추가합니다.

js
this.items = {
  _index: 0,
  create_dt: { selector: { key: `#create_dt${_SUFF}`, type: 'text' } }
};

command 서비스 객체 구성#

서버 경로에서 데이터를 가져오기 지정된 index 에 데이터를 value 을 가져오기 위해 outputOption: 'VIEW' 로 지정하였습니다.

처음으로 실행되는 cbBegin 콜백함수에 폼 추가 버튼 영역은 숨기고, 폼양식은 보이도록 설정합니다.

정적 JSON 데이터를 가져오기 위해서 임으로 _index을 임으로 지정하여 값을 가져올 수 있게 합니다.

js
this.command = {
  read: {
	outputOption: 'VIEW',
	cbBegin(model, cmd) {
	  cmd.outputOption.index = Number(cmd._model.items._index);
	  model.columns['_area_form'].value = ''; // form show
	  model.columns['_area_edit'].value = ''; // button show
	  model.columns['_area_create'].value = 'd-none';

	},

5-5 단계 : 명령(delete) 서비스 객체 구성#

삭제 버튼을 클릭하면 사용자에게 confirm() 확인 삭제 처리 후에 목록 보기로 이동합니다.

items 서비스 객체 구성#

기존의 items 사용합니다.

command 서비스 객체 구성#

cbValid 콜백함수를 활용해서 사용자에 삭제유무를 확인하도록 추가합니다.

cbEnd 콜백함수를 지정하여 삭제 처리 결과를 메세지로 표시합니다.

js
this.command = {
  delete: {
	cbValid(valid, cmd) {
	  if (confirm('Are you sure you want to delete it?')) return true;
	},
	cbEnd(status, cmd, res) {
	  if (res) {
		alert('The post has been deleted.');
		cmd._model.command['list'].execute();
	  }
	}
  }
};

js
this.mapping = {
  ntc_idx: { delete: ['valid', 'bind'] }
};

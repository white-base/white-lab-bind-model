고급 기능03

객체 구성 방법

서비스 객체, 모델, 명령을 활용한 구성 방법을 비교합니다.

한국어 문서약 11분

모델(BindModel)은 사용자의 다양한 요구에 맞게 여러 가지 생성 방식을 제공합니다. 각 방식의 특징과 장단점을 이해하고, 요구사항에 적합한 방법을 선택하여 사용할 수 있습니다.

서비스객체로 구성#

서비스 객체를 별도로 정의하여 관리하면, BindModel 객체를 한 번에 구성할 수 있습니다.

이 방식은 유지보수성과 재사용성을 높이는 데 효과적입니다.

js
const bm = new BindModel({
    // 추가 테이블 설정
    tables: ['second'],
    // 아이템 설정
    items: {
        'aa': 'Cat',
        'second.bb': 10,    // 'second' 테이블의 컬럼 설정
        'second.cc': true,  // 'second' 테이블의 컬럼 설정
        'dd': {
            selector: { key: '#U_ID', type: 'value' },  // 컬럼의 selector 설정
            setter: (val) => {/*외부에 설정 영역*/},        // 컬럼의 setter 설정
            getter: () => { return '외부값'; },           // 컬럼의 getter 설정
        },
        'ee': {
            required: true,                             // 컬럼의 required 설정
            setFilter: (val) => {/*외부에 설정영역*/},      // 컬럼의 setFilter 설정
            getFilter: () => { return '외부값'; },        // 컬럼의 getFilter 설정
        },
        'ff': {
            constraints: { reg: /abc/, msg: '매칭되지 실패!' } // 컬럼의 제약조건 설정
        }
    },
    // 명령(BindCommand) 설정
    command: {
        create: {},                     // 기본 명령 설정
        read: {
            outputOption: 'ALL',        // 데이터를 지정한 컬럼값에 설정
            config: { method: 'GET' },  // GET 요청 설정
            cbEnd: function() { alert('정상처리되었습니다.'); } // 처리 완료 후 콜백 함수
        },
        update: {
            views: ['two'],  // 'two' 뷰를 추가
            url: '/user'     // 요청할 URL 경로
        }
    }
});

setService(service) 메서드를 통해 필요한 시점에 서비스를 주입하며, 단계적으로 객체 구성을 완성할 수 있습니다.

Tip 서비스 객체를 생성하는 클래스를 정의하면, 재사용성과 관리 효율성을 높일 수 있습니다. 이를 통해 공통 로직을 캡슐화하고, 각 모델에서 필요한 맞춤 설정만 추가하여 사용할 수 있습니다.

참조 : 서비스 객체 주입

모델에서 구성#

모델(BindModel) 객체를 점진적으로 확장하거나, 컬럼을 여러 명령(BindCommand)에서 공통으로 사용해야 할 경우에 유용합니다.

js
const bm = new BindModel();

// 명령 추가
bm.addCommand('create');
bm.addCommand('read', 3);

// 'aa' 컬럼을 'create' 명령의 'valid' 뷰에 등록
bm.addColumn('aa', 'create', 'valid');
// 'bb' 컬럼을 'read' 명령의 'bind' 뷰에 등록
bm.addColumn('bb', 'read', 'bind');
// 'cc' 컬럼을 모든 명령의 'output' 뷰에 등록
bm.addColumn('cc', '$all', 'output');   

// bm.command['create'].valid.columns.count  == 1 ('aa')
// bm.command['create'].bind.columns.count   == 0
// bm.command['create'].output.columns.count == 1 ('cc')

// bm.command['read'].valid.columns.count    == 0
// bm.command['read'].bind.columns.count     == 1 ('bb')
// bm.command['read'].output.columns.count   == 1 ('cc')

// bm.columns.count  // 3 'aa','bb'

Tip '$all' 을 사용하면 모든 명령에 공통적으로 적용됩니다.

참조 : 모델 구성

명령에서 구성#

각 명령(BindCommand) 객체를 독립적으로 구성하는 방식입니다. 명령 단위로 컬럼이 독립적이거나, 특정 명령에만 컬럼을 설정할 경우 유용합니다.

명령에 컬럼 등록#

명령(BindCommand)을 추가하고, 해당 명령에 컬럼을 설정합니다.

js
const bm = new BindModel();

// 명령 추가
bm.addCommand('cmd1');
// 명령 설정
bm.command['cmd1'].url = '/user'
// 명령에 컬럼 추가
bm.command['cmd1'].addColumn('aa', 'valid');
bm.command['cmd1'].addColumn('bb', ['bind', 'output']);
bm.command['cmd1'].addColumn('cc', '$all');
bm.command['cmd1'].addColumn('dd');

// bm['first'].columns.count  == 4 ('aa', 'bb', 'cc', 'dd')

// bm.command['cmd1'].valid.columns.count  == 3 ('aa', 'cc', 'dd')
// bm.command['cmd1'].bind.columns.count   == 3 ('bb', 'cc', 'dd')
// bm.command['cmd1'].output.columns.count == 3 ('bb', 'cc', 'dd')

명령에 컬럼 참조 설정#

공유 컬럼을 명령에 따라 뷰(MetaView)에 등록하는 방식입니다. 명령 단위로 컬럼을 공유해야 할 때 유용합니다.

js
const bm = new BindModel();

// 컬럼 추가
bm.addColumn('aa');
bm.addColumn('bb');
bm.addColumn('cc', '$all');
bm.addColumn('dd');
// 명령 추가
bm.addCommand('cmd1');
// 명령에 컬럼 참조 설정
bm.command['cmd1'].setColumn('aa', 'valid');
bm.command['cmd1'].setColumn('bb', ['bind', 'output']);
bm.command['cmd1'].setColumn('cc', '$all');
bm.command['cmd1'].setColumn('dd');

// bm['first'].columns.count  == 4 ('aa', 'bb', 'cc', 'dd')

// bm.command['cmd1'].valid.columns.count  == 3 ('aa', 'cc', 'dd')
// bm.command['cmd1'].bind.columns.count   == 3 ('bb', 'cc', 'dd')
// bm.command['cmd1'].output.columns.count == 3 ('bb', 'cc', 'dd')

Tip 사용하는 조건에 맞게 객체 생성방식을 자유롭게 조합해서 사용할 수 있습니다.

참조 : 명령 구성

객체 구성 비교#

아래 예제는 'bb' 속성을 공유하며 공통 컬럼 아이템을 사용하는 방식으로 동일한 객체를 다양한 방법으로 구성한 예입니다.

방식 특징 비고
서비스 객체로 구성 전체적인 구조를 한 번에 정의하고 관리할 때 적합
모델에서 컬럼 구성 공통 컬럼이 여러 명령에서 공유될 때 적합
명령에서 컬럼 구성 명령마다 컬럼이나 설정이 독립적일 때 적합

Tip 필요에 따라 위 방식을 혼합하여 사용할 수도 있습니다.

서비스 객체로 구성#

서비스 객체를 통해 모델(BindModel)을 한 번에 구성합니다.

js
const bm = new BindModel();

bm.setService({
    // 추가 테이블
    tables: 'second',
    // 아이템
    items: {
        aa: 'AA',
        bb: 10,
        cc: true,
        dd: { required: true },
    },
    // 명령
    command: {
        cmd1: {},
        cmd2: {
            outputOption: 'ALL',        // 데이터를 컬럼값에 설정하기 (지정한 컬럼)
            config: { method: 'GET' },  // GET 요청 설정
            cbEnd: () => { alert('정상처리되었습니다.') } // 처리 완료 후 콜백 함수
        },
        cmd3: {
            views: ['two'],  // 'two' 뷰를 추가
            url: '/user'     // 요청할 URL 경로
        }
    },
    // 매핑
    mapping: {
	    'aa': { cmd1: 'valid' },
	    'bb': { cmd2: ['valid', 'bind'], cmd3: 'output' },
	    'second.cc': { cmd3: 'output' },
	    'second.dd': { cmd3: '$all' }
    }
});

Tip 서비스 객체를 사용하면 초기 설정 및 구성이 간편하며, 한눈에 객체 구조를 파악할 수 있습니다.

명령에서 컬럼 구성#

명령(BindCommand) 중심으로 객체를 구성하며, 단계별로 컬럼을 추가하고 매핑합니다.

js
const bm = new BindModel();
// 추가 테이블
bm.addTable('second');
// 아이템 추가
bm.items.add('aa', AA);
bm.items.add('bb', 10);
bm.items.add('cc', true);
bm.items.add('dd', { required: true });
// 명령 추가
bm.addCommand('cmd1');
bm.addCommand('cmd2', 3);
bm.addCommand('cmd3');
// 명령 설정
bm.commmand['cmd2'].config.method = 'GET';
bm.commmand['cmd2'].cbEnd = () => { alert('정상처리되었습니다.') };
bm.commmand['cmd3'].newOutput('two');
bm.commmand['cmd3'].url = '/user';
// 컬럼 추가 및 매핑
bm.commmand['cmd1'].addColumn('aa', 'valid');
bm.commmand['cmd2'].addColumn('bb', ['valid', 'bind']);
bm.commmand['cmd3'].addColumn('bb', 'output');
bm.commmand['cmd3'].addColumn('cc', 'output', 'second');
bm.commmand['cmd3'].addColumn('dd', '$all', 'second');

Tip 명령에서 컬럼을 개별적으로 설정하면 명령 단위로 유연하게 구성할 수 있습니다.

모델에서 컬럼 구성#

모델(BindModel) 중심으로 테이블, 아이템, 컬럼을 먼저 등록한 뒤 명령에 매핑합니다.

js
const bm = new BindModel();
// 추가 테이블
bm.addTable('second');
// 아이템 추가
bm.items.add('aa', AA);
bm.items.add('bb', 10);
bm.items.add('cc', true);
bm.items.add('dd', { required: true });
// 컬럼 추가 및 매핑
bm.addColumn('aa', 'cmd1', 'valid');
bm.addColumn('bb', 'cmd2', ['valid', 'bind']);
bm.addColumn('bb', 'cmd3', 'output');
bm.addColumn('cc', 'cmd3', 'output', 'second');
bm.addColumn('dd', 'cmd3', '$all', 'second');
// 명령 설정
bm.commmand['cmd2'].outputOption = 'ALL';
bm.commmand['cmd2'].config.method = 'GET';
bm.commmand['cmd2'].cbEnd = () => { alert('정상처리되었습니다.') };
bm.commmand['cmd3'].newOutput('two');
bm.commmand['cmd3'].url = '/user';

Tip 모델 중심 구성은 공통 컬럼을 여러 명령에서 사용해야 할 때 적합하며, 컬럼과 명령을 명시적으로 관리할 수 있습니다.

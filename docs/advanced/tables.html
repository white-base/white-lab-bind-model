테이블 관리

복수의 테이블로 데이터를 나누고 기본 테이블을 설정합니다.

한국어 문서약 16분

모델(BindModel)은 기본적으로 first 속성의 기본 테이블(MetaTable)을 제공합니다.

js
bm.first === bm._tables['first'] === bm._tables[0];
  • first 속성은 _tables['first'] 의 참조값입니다.

추가 테이블은 _tables 컬렉션에 저장되며, 테이블 이름이 BindModel 객체에 속성으로 추가됩니다.

js
const bm = new BindModel();

// 테이블 추가
bm.addTable('second');
bm.addTable('third');

// bm._tables['second'] === bm.second
// bm._tables['third'] === bm.third

테이블 추가하기#

테이블을 추가하면 컬럼명 중복 문제를 해결하고 데이터를 논리적으로 분리할 수 있습니다.

ts
declare function addTable(tableName: string, isBaseTable?: boolean): MetaTable;
  • isBaseTable을 true로 지정하면, 해당 테이블이 기본 테이블(_baseTable)로 설정됩니다.

addTable() 메소드를 사용하여 새로운 테이블을 추가합니다.

추가된 테이블은 _tables 컬렉션에 등록되며, 해당 테이블은 BindModel 객체의 속성으로 자동 추가되어 사용할 수 있습니다.

js
const bm = new BindModel();

// 'second' 및 'three' 테이블 추가
bm.addTable('second');
bm.addTable('three');

// bm.second === _tables['second'] === _tables[1]
// bm.three  === _tables['three']  === _tables[2]

Tip

테이블 이름은 모델(BindModel)의 키값과 중복되지 않아야 합니다. 예약어 목록 : _tables, _baseTable, _columnType, items, fn, command, cmd, columns, '$service', 'baseConfig', 'url', '_guid', '_type', '$event', '$KEYWORD'

컬럼 중복 문제 해결#

서버 데이터에서 동일한 컬럼명이 여러 번 등장할 경우, 다른 테이블에 분리하여 관리할 수 있습니다.

js
bm.addTable('second');
bm.addTable('three');

bm.second.columns.add('age');    // 'second' 테이블에 'age' 컬럼 추가
bm.three.columns.add('age');     // 'three' 테이블에 'age' 컬럼 추가

Tip 전송하거나 수신하는 데이터의 이름이 중복될 경우, 컬럼 별칭(alias)을 통해 충돌을 피할 수 있습니다.

기본 테이블 변경#

_baseTable은 모델(BindModel)의 기본 테이블을 가리킵니다.

기본 테이블은 컬럼(HTMLColumn)이나 명령(BindCommand)을 추가할 때, 특정 테이블이 지정되지 않으면 자동으로 선택되는 테이블입니다.

columns 속성은 기본 테이블의 컬럼 컬렉션을 참조합니다.

js
bm._baseTable === bm._tables['first'] === bm.first;
bm.columns === bm._baseTable.columns;

addTable() 메서드로 테이블을 추가할 때, 매개변수를 지정하여 해당 테이블을 기본 테이블로 설정할 수 있습니다.

js
const bm = new BindModel();

bm.addTable('second', true);

// bm._baseTable === bm.second
// bm.columns === bm.second.columns === bm._baseTable.columns
  • _baseTable 값을 변경하면 columns 참조도 변경됩니다.

_baseTable 속성을 설정하면 기본 테이블을 변경할 수 있습니다.

js
const bm = new BindModel();

bm.addTable('second', true);

// 기본 테이블 변경
bm._baseTable = bm.second;  

// bm._baseTable === bm.second
// bm.columns === bm.second.columns === bm._baseTable.columns

명령에 기본 테이블 설정#

명령(BindCommand)을 추가할 때, 특정 테이블을 명령의 기본 테이블로 지정할 수 있습니다. 이 기본 테이블은 해당 명령 내에서 컬럼을 추가하거나 참조할 때 사용됩니다.

Note 모델(BindModel)과 명령(BindCommand) 객체는 각각 _baseTable 속성을 가지고 있습니다. BindModel의 _baseTable은 공통 컬럼 등록 및 명령의 기본 테이블로 사용되며, BindCommand의 _baseTable은 해당 명령 전용의 기본 테이블로 사용됩니다.

js
bm.addCommand('cmd1', 'SEND', 'second');

// bm.command['cmd1']._baseTable === bm.second

명령(BindCommand)에서 컬럼을 추가하면 _baseTable 로 지정된 테이블에 추가됩니다.

Tip

명령(BindCommand) 추가할 때 기본테이블이 생략되면, 모델의 기본테이블이 기본값으로 설정됩니다.

js
const bm = new BindModel();

bm.addTable('second');    // 'second' 테이블 추가
bm.addCommand('create', 'VIEW', 'second');  // 명령 추가

// 컬럼 추가
bm.command['create'].addColumn('age');      // 'second' 테이블에 'age' 컬럼 생성
bm.command['create'].addColumn('tel');    // 'second' 테이블에 'tel' 컬럼 생성

명령(BindCommand)의 _baseTable을 변경하면, 이후 생성하는 컬럼은 변경된 기본 테이블을 기준으로 추가됩니다.

js
const bm = new BindModel();

bm.addTable('second');    // 'second' 테이블 추가
bm.addCommand('create');  // 명령 추가

// 컬럼 추가
bm.command['create'].addColumn('age');      // 'first' 테이블에 'age' 컬럼 생성

// 명령의 기본 테이블 변경
bm.command['create']._baseTable = 'second';

// 컬럼 추가
bm.command['create'].addColumn('tel');    // 'second' 테이블에 'tel' 컬럼 생성

테이블 컬럼 추가 및 매핑#

Tip

컬럼명 이름 규칙 : [테이블명 . ]컬럼명 테이블명이 생략 되면 기본테이블에 등록됩니다.

컬럼 추가하기#

기본 테이블에 추가#

기본테이블에 컬럼을 추가합니다.

js
bm.addColumn('aa');
bm.addColumnValue('bb', 10);
bm.addSelector('cc', '#tel');

// bm.first.columns['aa'] instanceof MetaColumn : true
// bm.first.columns['bb'] instanceof MetaColumn : true
// bm.first.columns['cc'] instanceof MetaColumn : true

지정한 테이블에 추가#

지정한 테이블에 컬럼을 추가합니다.

js
// 'second' 테이블에 컬럼 추가
bm.addColumn('aa', null, null, 'second');
bm.addColumn('bb', null, null, bm.second);

컬럼을 추가하면서 초기값을 설정합니다.

js
bm.addColumnValue('cc', 10,  null, null, 'second');
bm.addColumnValue('dd', 'B', null, null, bm.second);

// bm.second.columns.count  == 2
// bm.second.columns['cc'].value  == 10
// bm.second.columns['dd'].value  == 'B'

컬럼을 추가하면서 셀렉터 값을 설정합니다.

js
bm.addSelector('cc', '#age',  null, null, 'second');
bm.addSelector('dd', '#tel', null, null, bm.second);

// bm.second.columns.count  == 2

추가된 테이블의 컬렉션을 직접 사용하여 컬럼을 추가할 수도 있습니다.

js
bm.second.columns.add('aa');
bm.second.columns.addValue('bb', 10);

// bm.second.columns.count  == 2
// bm.second.columns['aa'].value == null
// bm.second.columns['bb'].value == 10

컬럼 추가 및 매핑하기#

빈 컬럼 추가#

특정 테이블에 컬럼을 추가하고, 명령(BindCommand)의 전체 뷰(valid, bind, output, misc)에 매핑합니다.

Tip

뷰를 생략하면 전체 뷰($all)에 매핑됩니다.

js
bm.addColumn('aa', 'cmd1', '$all', 'second');

// bm['second'].columns.count  == 1 ('aa')

// bm.command['cmd1'].valid.columns.count  == 1 ('aa')
// bm.command['cmd1'].bind.columns.count   == 1 ('aa')
// bm.command['cmd1'].output.columns.count == 1 ('aa')

특정 명령과 뷰(MetaView)에 매핑합니다.

js
bm.addColumn('bb', ['cmd2', 'cmd3'], ['valid', 'bind'], 'second');

// bm['second'].columns.count  == 1 ('bb')

// bm.command['cmd2'].valid.columns.count  == 1 ('bb')
// bm.command['cmd2'].bind.columns.count   == 1 ('bb')
// bm.command['cmd2'].output.columns.count == 0

// bm.command['cmd3'].valid.columns.count  == 1 ('bb')
// bm.command['cmd3'].bind.columns.count   == 1 ('bb')
// bm.command['cmd3'].output.columns.count == 0

모든 명령($all)과 특정 뷰(MetaView)에 매핑합니다.

js
// 명령 추가
bm.addCommand('cmd1');
bm.addCommand('cmd2');

// 컬럼 추가 및 매핑
bm.addColumn('cc', '$all', 'output', 'second');

// bm['second'].columns.count  == 1 ('cc')
// bm.command['cmd1'].output.columns.count == 2 ('cc')
// bm.command['cmd2'].output.columns.count == 1 ('cc')
  • '$all' 지시자는 모든 명령(BindCommand)객체가 선택됩니다. : cmd1, cmd2

초기값으로 컬럼 추가#

특정한 테이블에 컬럼을 추가하면서 초기값을 설정하고, 명령(BindCommand)의 뷰(MetaView)에 매핑합니다.

js
const bm = new BindModel();

// 테이블 추가
bm.addTable('second');

// 초기값이 있는 컬럼 추가 및 매핑
bm.addColumnValue('aa', 10, 'cmd1', '$all', 'second');

// bm['second'].columns.count  == 1 ('aa')
// bm.second.columns['aa'].value  == 10

// bm.command['cmd1'].valid.columns.count  == 1 ('aa')
// bm.command['cmd1'].bind.columns.count   == 1 ('aa')
// bm.command['cmd1'].output.columns.count == 1 ('aa')

특정한 테이블에 컬럼을 추가하면서 초기값을 설정하고, 선택된 명령(BindCommand)의 지정한 뷰(MetaView)에 매핑합니다.

js
const bm = new BindModel();

// 테이블 추가
bm.addTable('second');

// 초기값이 있는 컬럼 추가 및 매핑
bm.addColumnValue('bb', 'B', ['cmd1', 'cmd2'], ['valid', 'bind'], 'second');

// bm.second.columns.count  == 1 ('bb')
// bm.second.columns['bb'].value  == 'B'

// bm.command['cmd1'].valid.columns.count  == 1 ('bb')
// bm.command['cmd1'].bind.columns.count   == 1 ('bb')
// bm.command['cmd1'].output.columns.count == 0 

// bm.command['cmd2'].valid.columns.count  == 1 ('bb')
// bm.command['cmd2'].bind.columns.count   == 1 ('bb')
// bm.command['cmd2'].output.columns.count == 0
  • 컬럼을 추가할 때, 명령과 뷰를 함께 지정하여 등록할 수 있습니다.

Tip

addColumnValue() 메서드는 addColumn()에 초기값 설정 기능이 추가된 메서드입니다.

명령에서 컬럼 추가하기#

명령(BindCommand)에서 컬럼을 추가하려면, 먼저 명령과 특정 테이블을 추가합니다.

js
const bm = new BindModel();

bm.addTable('second');  // 'second' 테이블 추가
bm.addCommand('cmd1');  // 'cmd1' 명령 추가

명령(BindCommand)에 특정 뷰(valid)와 테이블을 지정하여 컬럼을 추가합니다.

js
bm.command['cmd1'].addColumn('aa', 'valid', bm.second);

// bm['second'].columns.count  == 1 ('aa')
// bm.command['cmd1'].valid.columns.count  == 1 ('aa')
// bm.command['cmd1'].bind.columns.count   == 0
// bm.command['cmd1'].output.columns.count == 0

명령(BindCommand)에 특정 뷰(bind, output)와 테이블을 지정하여 컬럼을 추가합니다.

js
bm.command['cmd1'].addColumn('bb', ['bind', 'output'], 'second');

// bm.command['cmd1'].valid.columns.count  == 0
// bm.command['cmd1'].bind.columns.count   == 1 ('bb')
// bm.command['cmd1'].output.columns.count == 1 ('bb')

명령(BindCommand)에 모든 뷰(valid, bind, output)와 테이블을 지정하여 컬럼을 추가합니다.

js
bm.command['cmd1'].addColumn('cc', '$all', 'second');

// bm.command['cmd1'].valid.columns.count  == 2 ('cc')
// bm.command['cmd1'].bind.columns.count   == 2 ('cc')
// bm.command['cmd1'].output.columns.count == 2 ('cc')

기존 컬럼 등록하기#

모델(BindModel) 객체에 테이블과 기본 컬럼을 추가하고, 명령(BindCommand) 객체의 특정 뷰(MetaView)에 컬럼을 참조로 등록합니다.

모델을 생성하고 테이블과 컬럼을 생성하는 예제입니다.

js
const bm = new BindModel();

// 'second' 테이블 추가
bm.addTable('second');  

// 기본 테이블에 컬럼 추가
bm.addColumn('aa');
bm.addColumn('bb');

// 'second' 테이블에 컬럼 추가
bm.second.columns.add('cc');
bm.second.columns.add('dd');

// bm.first.columms.count  == 2 ('aa', 'bb')
// bm.second.columms.count == 2 ('cc', 'dd')
  • 'aa', 'bb' 컬럼은 기본테이블에 추가됩니다.
  • 'cc', 'dd' 컬럼은 'second' 테이블에 추가됩니다.

명령을 추가하고 지정한 뷰(valid)에 기본테이블(first)의 컬럼을 설정하는 예제입니다.

js
bm.addCommand('cmd1');

bm.command['cmd1'].setColumn('aa', 'valid');

// bm.command['cmd1'].valid.columns.count  == 1 ('aa')
// bm.command['cmd1'].bind.columns.count   == 0
// bm.command['cmd1'].output.columns.count == 0

명령을 추가하고 지정한 뷰(bind)에 기본테이블(first)과 추가테이블(second)의 컬럼을 설정하는 예제입니다.

js
bm.addCommand('cmd2');

bm.command['cmd2'].setColumn(['bb', 'second.cc'], 'bind');

// bm.command['cmd2'].valid.columns.count == 0
// bm.command['cmd2'].bind.columns.count == 2 ('bb', 'dd')
// bm.command['cmd2'].output.columns.count == 0

명령을 추가하고 전체 뷰(valid, bind, output, misc)에 추가테이블(second)의 컬럼을 설정하는 예제입니다.

js
bm.addCommand('cmd3');

bm.command['cmd3'].setColumn('second.dd', '$all');

// bm.command['cmd3'].valid.columns.count  == 1 ('dd')
// bm.command['cmd3'].bind.columns.count   == 1 ('dd')
// bm.command['cmd3'].output.columns.count == 1 ('dd')

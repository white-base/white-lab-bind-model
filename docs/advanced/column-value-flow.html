컬럼값 호출 구조

값을 읽고 쓸 때 getter, setter, selector가 작동하는 구조를 살펴봅니다.

한국어 문서약 19분
1.1.13에서 필터를 사용할 때

이 배포 버전에서는 getFilter로 값을 읽을 때 selector 설정이 필요합니다. DOM을 읽지 않는 필터에는 selector: { key: '#example', type: 'none' }을 함께 설정하세요. key는 실제 사용하는 요소에 맞춰 지정합니다.

컬럼의 value 값을 조회하거나 설정할 때 다양한 설정 방식을 활용하여 유연하게 구성할 수 있습니다.

컬럼값(value) 조회#

컬럼값 조회 시, 다음과 같은 우선순위에 따라 적합한 값을 선택합니다.

  1. getter : 값 조회 시 우선적으로 실행되는 사용자 정의 함수입니다.
  2. getFilter : getter가 없을 경우, 값을 변환하기 위한 필터 함수입니다.
  3. selector : DOM 요소에서 값을 가져옵니다.
  4. 내부값 : 컬럼에 저장된 내부 value 값입니다.
  5. 기본값(default) : value나 다른 설정이 없을 경우 반환되는 기본값입니다.

조회 내부 구조#

컬럼값 조회 단계#

  1. getter 확인
    • getter 함수가 설정되어 있으면, 이를 호출하여 반환된 값을 사용합니다.
  2. getFilter 확인
    • getter가 없을 경우, getFilter가 설정되어 있으면 이를 통해 값을 변환합니다.
    • 만약 selector가 동시에 있으면 selector로 값을 가져온 후 getFilter를 거쳐 반환합니다.
  3. selector 확인
    • getter와 getFilter가 없고, selector가 설정되어 있으면 selector의 type에 따라 값을 가져옵니다.
  4. 내부값 확인
    • getter, getFilter, selector가 모두 없으면 컬럼에 저장된 내부 값을 반환합니다.
    • getter, getFilter, selector 에서 반환값이 null, undefined 이면 내부값을 반환합니다.

Note 값 조회 시에는 우선순위에 따라 적절한 값이 선택됩니다.

컬럼값(value) 설정#

컬럼값을 설정할 때, 아래 속성에 따라 병렬로 값을 저장하며, 각 단계는 독립적으로 실행됩니다. 즉, setter, setFilter, selector가 모두 설정되어 있으면 각각에 값을 저장합니다.

컬럼값 설정 시, 다음과 같은 순위에 따라 값을 설정합니다.

  1. setter : 값 설정 시 우선적으로 실행되는 사용자 정의 함수입니다.
  2. 내부값 : 컬럼에 저장된 내부 value 값에 저장합니다.
  3. setFilter : 값을 변환하여 설정하기 위한 필터 함수입니다.
  4. selector : DOM 요소에서 값을 설정합니다.

설정 내부 구조#

컬럼값 설정 단계#

  1. setter 호출
    • setter 함수가 설정되어 있으면, 이를 호출하여 값을 처리합니다.
    • setter 함수가 값을 리턴하는 경우, 리턴값이 내부값으로 저장됩니다.
  2. 내부값 저장
    • 설정된 값은 내부값으로 저장됩니다.
    • 만약 setter가 값을 리턴하면, 리턴값이 내부값으로 저장됩니다.
  3. setFilter 호출
    • setFilter가 설정되어 있으면, 설정된 함수가 호출되어 값이 변환됩니다.
  4. selector 설정
    • selector가 설정되어 있으면, type에 따라 DOM 요소에 값을 설정합니다.
    • setFilter 함수가 값을 리턴하는 경우, 리턴값이 selector에 값으로 저장됩니다.
    • type이 none이면 무시됩니다.

Note 값을 설정할 때는 정의된 순서에 따라 순차적으로 적용되며, 일부 항목은 병렬로 처리될 수 있습니다.

컬럼값 구성 빈도#

컬럼값은 다양한 환경과 요구에 따라 조회와 설정을 위한 속성이 다르게 구성됩니다. 아래는 컬럼값을 설정하거나 조회할 때 사용되는 속성의 빈도와 주요 사용 예를 설명합니다.

빈도 setter setFilter selector getFilter getter 설명
89% 사용 - DOM 요소에 직접 연결 <br>- 단일 HTML 요소와 연동 <br>- 예시> 태그 p, input, select, css
3% 사용 사용 - 외부 변수나 객체를 참조<br>- page_count 등 비 DOM 데이터
3% 사용 사용 사용 - 외부 객체와 DOM을 동시 제어<br>- 예시> page_size <br>(HTML select 값과 연동)
3% 사용 사용 - 복합 DOM 요소를 제어 <br>- 예시> 라디오 버튼, 내부값과 화면값이 다른 경우
1% 사용 사용 - HTML 표현값을 가공하는 경우<br>- 예시> 숫자를 통화 형식으로 표시
1% 사용 - HTML 표현과 상관없이 내부적으로만 변환 <br>- 예시> 코드 값 변환, 선택값 표시
  • 샘플 : 쇼핑몰, DB Table 36EA 기준

Note 값의 성격에 따라 setter, getter, setFilter, getFilter, selector를 적절히 조합함으로써, 다양한 조건에 대응하는 컬럼 구성을 할 수 있습니다.

selector 를 사용한 경우#

selector는 DOM 요소와 직접 연결하여 값을 가져오거나 설정합니다.

html
<div id="idx"><p style="color:red;">10</p></div>
<input id="title" type="text" value="AA" />
<input id="chk_yn" type="checkbox" checked />
<a href="http://google.com">google.com</a>
js
var bm = new BindModel();

bm.addSelector('aa', { key:'#idx',    type: 'html' });
bm.addSelector('bb', { key:'#idx',    type: 'text' });
bm.addSelector('cc', { key:'title',   type: 'value' });
bm.addSelector('dd', { key:'#chk_yn', type: 'prop.checked' });
bm.addSelector('ee', { key:'a',       type: 'attr.href' });
bm.addSelector('ff', { key:'p',       type: 'css.color' });

// bb.columns['aa'].value == '<p style="color:red;">10</p>'
// bb.columns['bb'].value == '10'
// bb.columns['cc'].value == 'AA'
// bb.columns['dd'].value == true
// bb.columns['ee'].value == 'http://google.com'
// bb.columns['ff'].value == 'red'
  • 셀렉터에 문자열 키를 지정하면, 해당 DOM 요소를 검사하여 value, text, html 중 적절한 타입이 자동으로 지정됩니다.

Tip

selector 지정한 값이 여러개 존재하면, 첫번째 값을 가져오거나, 설정합니다.

setter, getter 을 사용한 경우#

외부 변수와 컬럼을 연동할 때 사용합니다.

js
const bm = new BindModel();
let page_size = 10;

bm.addColumnValue('aa', {
	getter: function() { return page_size },
	setter: function(nVal) { page_size = nVal }
});

// bm.columns['aa'].value === 10

Tip

단방향으로 외부값을 읽기전용으로 사용할려면 getter 함수만 정의합니다.

selector, setter, getter 를 조합한 경우#

HTML 요소와 외부 변수를 동시에 제어합니다.

html
<select id="page_size">
    <option value="10">10EA</option>
    <option value="20">20EA</option>
    <option value="30">30EA</option>
</select>
js
const bm = new BindModel();
let page_size = 10;

bm.addColumnValue('aa', {
	getter: function() { return page_size },
	setter: function(nVal) { page_size = nVal },
	selector: { key: '#page_size',  type: 'value' }
});

// bm.columns['aa'].value === 10

// jQuery를 이용하여 DOM 값 변경
$("#page_size").val("20");
// bm.columns['aa'].value === 20

// 컬럼 value 값 변경
bm.columns['aa'].value = 30;
// bm.columns['aa'].value === 30
// page_size === 30
// $("#page_size").val() == '30'
  • 값을 가져올 때는 우선순우가 높은 getter 을 호출하여 값을 가져옵니다.
  • 값을 설정할 때는 setter 와 selector 두곳에 값을 설정합니다.

setFilter, getFilter 을 사용한 경우#

컬럼 값이 여러 요소와 연관되어 있을 경우에는 setFilter와 getFilter를 사용하여 값을 변환하거나 가공할 수 있습니다.

html
<input type="radio" name="gender" value="woman" />
<input type="radio" name="gender" value="man" />
js
const bm = new BindModel();

bm.addColumnValue('aa', {
	getFilter: function() { 
		return $('input[name=gender]:checked').val(); 
	},
	setFilter: function(nVal) { 
		$('input[name=gender][value='+ newVal + ']').prop('checked', true);
	}
});

// bm.columns['aa'].value == ''
$('input[name=gender][value=man]').prop('checked', true); // radio choice
// bm.columns['aa'].value == 'man'

내부 값과 표시 값이 다를 경우, getFilter와 setFilter를 사용해 숫자를 통화 형식 등으로 변환할 수 있습니다.

html
<p id="sum"></p>
js
const bm = new BindModel();
bm.columns.addValue('price', {
    setFilter: (val) => {
        const formatted = Number(val).toLocaleString();
        $("#sum").text(formatted);
    },
    getFilter: () => {
        return parseInt($("#sum").text().replace(/,/g, ""));
    }
});

// 값 설정 및 표시
bm.columns['price'].value = 10000;

// DOM 값 확인
console.log($("#sum").text());          // "10,000"

// 값 조회
console.log(bm.columns['price'].value); // 10000
  • 내부적으로는 10000 값으로 저장되고, 화면에는 콤마가 포함된 10,000으로 표시됩니다.

selector 객체#

selector 객체는 컬럼값을 DOM 요소의 값을 참조하여 설정하거나 가져오는 데 사용됩니다. 이 객체를 사용하면 HTML 요소와 모델 간의 데이터를 동기화할 수 있습니다.

type 설명 비고
'value' | 'val' DOM 요소의 value 값을 가르킵니다. 'val' 은 축약어
'text' 지정한 위치의 text 값을 가르킵니다. 태그 제외
'html' 지정한 위치의 html 태그값을 가르킵니다.
'attr.*' HTML 속성명의 값을 가르킵니다. 예> 'attr.value', 'attr.type'
'prop.*' DOM 객체의 속성명의 값을 가르킵니다. 예> 'prop.checked'
'css.*' css 속성값을 가르킵니다 jquery(셀렉터).css(속성명) 사용
'none' 값을 사용하지 않습니다. 유효성 검사 등에서 활용

value 타입#

DOM 요소의 value 값을 참조합니다. <input> 또는 <select> 요소에 주로 사용됩니다.

html
<input type="text" id="user_name" value="mike"/>
<select id="color_name">
  <option value="red" selected>Red</option>
  <option value="green">Blue</option>
  <option value="blue">Green</option>
</select>

컬럼 등록시 설정할 경우#

js
bm.addSelector('aa', { key: '#user_name',  type: 'value' });
bm.addSelector('bb', { key: '#color_name', type: 'value' });

// bm.columns['aa'].value = 'Mike'
// bm.columns['bb'].value = 'red'

기존 컬럼에 설정할 경우#

js
bm.addColumn('aa');
bm.addColumn('bb');

bm.columns['aa'].selector = { key: '#user_name',  type: 'value' };
bm.columns['bb'].selector = { key: '#color_name',  type: 'value' };

// bm.columns['aa'].value = 'Mike'
// bm.columns['bb'].value = 'red'

Tip jQuery(셀렉터).val()과 동일한 결과를 반환합니다.

태그를 제외한 순수 텍스트를 가져오거나 설정합니다.

// bm.columns['aa'].value = 'mike'
// bm.columns['bb'].value = 'mike1000'

기존 컬럼에 설정할 경우#

js
bm.addColumn('aa');

Tip jQuery(셀렉터).text()와 동일한 결과를 반환합니다.

html 타입#

bm.addSelector('aa', { key: '#content', type: 'html' });

// bm.columns['aa'].value === '<p style="color:red;">Hello</p>'

기존 컬럼에 설정할 경우#

js
bm.addColumn('aa');

bm.columns['aa'].selector = { key: '#content', type: 'html' };

// bm.columns['aa'].value === '<p style="color:red;">Hello</p>'

Tip jQuery(셀렉터).html()과 동일한 결과를 반환합니다.

attr 타입#

HTML 속성 값을 참조합니다.

html
<input id="user_name" type="text" flag="OK" />
js
bm.addSelector('aa', { key: '#user_name', type: 'attr.flag' });

// bm.columns['aa'].value === 'OK'

Tip jQuery(셀렉터).attr(속성명)과 동일한 결과를 반환합니다.

prop 타입#

DOM 객체의 속성 값을 참조합니다.

html
<input id='agree' type="checkbox" class="item" value="Y" />
js
bm.addSelector('aa', { key: '#agree', type: 'prop.checked' });
// bm.columns['aa'].value === false

$('#agree').prop('checked', true);  // checkbox choice
// bm.columns['aa'].value === true

Tip jQuery(셀렉터).prop(속성명)과 동일한 결과를 반환합니다.

css 타입#

CSS 속성 값을 참조합니다.

html
<div id="title" style="color: black; padding: 10px;">Text Content</div>
js
bm.addSelector('aa', { key: '#title', type: 'css.color' });
bm.addSelector('bb', { key: '#title', type: 'css.padding' });

// bm.columns['aa'].value === 'black'
// bm.columns['bb'].value === '10px'

Tip jQuery(셀렉터).css(속성명) 을 사용한 결과와 동일합니다.

none 타입#

type을 'none'으로 설정하면 값을 사용하지 않습니다. 유효성 검사와 같은 검증 작업에 활용됩니다.

html
<input id="memo" type="text" value="Not Used" />
js
bm.addSelector('aa', { key: '#memo', type: 'none' });

// bm.columns['aa'].value === undefined

Tip

  • 값 조작 및 검증
    • none 타입은 UI 값이 아닌 상태만 검증하거나 이벤트 트리거에 활용할 수 있습니다.
  • DOM 동기화
    • value, text, html 타입은 데이터와 UI 동기화를 쉽게 관리할 수 있습니다.
  • 속성 및 스타일 제어
    • attr, prop, css 타입은 DOM 속성과 스타일을 효과적으로 제어합니다.

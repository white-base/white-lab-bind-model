명령 복수 출력 구성

하나의 명령에서 여러 출력 뷰를 구성하고 응답을 처리합니다.

한국어 문서약 13분

서버에서 다중 엔티티(테이블) 데이터를 응답받을 경우, 명령(BindCommand) 객체에서 복수의 출력 뷰(MetaView)를 구성하여 데이터를 처리할 수 있습니다.

_outputs 컬렉션의 구조#

명령(BindCommand) 객체는 _outputs 컬렉션을 통해 여러 출력 뷰(MetaView)를 관리합니다.

  • 기본 출력 뷰는 output 속성을 통해 접근할 수 있으며, 이는 _outputs['output1']를 참조합니다.

  • 추가 출력 뷰는 newOutput() 메서드를 통해 생성되며, _outputs 컬렉션에 등록됩니다.

출력 뷰(MetaView) 추가#

newOutput() 메서드를 사용하여 명령(BindCommand) 객체에 출력 뷰를 추가할 수 있습니다.

ts
declare function newOutput(outputName?: string): void;
  • outputName : 새롭게 추가할 출력 뷰의 이름입니다.

이름을 지정하지 않은 경우, 기본 이름 규칙('output' + 숫자)에 따라 출력 뷰가 자동으로 추가됩니다.

Tip 명령(BindCommand) 객체에는 output과 output1 속성이 기본으로 제공되며, 두 속성은 동일한 값을 참조합니다.

기본 출력 뷰 추가#

아무 이름도 지정하지 않을 경우, 기본 이름 규칙('output' + number)에 따라 출력 뷰가 추가됩니다.

js
const bm = new BindModel();

// 명령 추가
bm.addCommand('cmd1');  

// 출력 뷰 추가
bm.cmd['cmd1'].newOutput();  

// bm.command['cmd1'].output2 instanceof MetaView
// bm.command['cmd1'].output2 === bm.command['cmd1']._outputs['output2']

Tip 기본 출력 뷰 이름은 output2, output3, … 순으로 자동 생성됩니다.

사용자 지정 출력 뷰 추가#

사용자 정의 이름을 사용하면 기본 출력 뷰와 사용자 정의 이름으로 출력 뷰가 추가됩니다.

js
bm.cmd['cmd1'].newOutput('three');

// bm.command['cmd1'].output3 instanceof MetaView
// bm.command['cmd1'].three instanceof MetaView
// bm.command['cmd1'].output3 === bm.command['cmd1'].three

Tip

출력 뷰 이름이 명령(BindCommand)의 키값과 중복되지 않아야 합니다. 예약어 목록 : config, url, _outputs, _model, _baseTable, valid, bind, output, output1, misc, outputOption, outOpt, cbBind, cbValid, cbBind, cbResult, cbOutput, cbEnd, _guid, _type

출력 뷰(MetaView) 제거#

명령(BindCommand) 객체에서 추가한 출력 뷰(MetaView)를 제거할 수 있습니다.

ts
declare function removeOutput(outputName: string): void;
  • outputName : 제거할 출력 뷰(MetaView)의 이름입니다.

출력 뷰를 제거할 때, 기본적으로 생성된 'output' + 숫자 형식의 자동 속성명도 함께 제거됩니다.

js
const bm = new BindModel();

bm.addCommand('cmd1');
// bm.cmd['cmd1']._outputs.count == 1

// 기본 출력 뷰 생성
bm.cmd['cmd1'].newOutput();  // output2 생성
// bm.cmd['cmd1']._outputs.count == 2

// 제거
bm.cmd['cmd1'].removeOutput('output2');
// bm.cmd['cmd1']._outputs.count == 1

사용자 정의 이름을 사용해 추가한 출력 뷰를 제거합니다.

js
bm.cmd['cmd1'].newOutput('three');
// bm.cmd['cmd1']._outputs.count == 2
// bm.command['cmd1'].output2 == MetaView
// bm.command['cmd1'].three == MetaView

// Remove
bm.cmd['cmd1'].removeOutput('three');
// bm.cmd['cmd1']._outputs.count == 1

Tip

기본 뷰인 output 또는 output1 속성은 제거할 수 없습니다.

출력 뷰 가져오기#

서버 응답 데이터가 여러 엔티티로 구성된 경우, 출력 뷰(MetaView)를 활용하여 데이터를 가져올 수 있습니다. 출력 옵션(opt)에 따라 데이터 처리 방식이 달라집니다.

json
// SERVER DATA
[
	{
	    "rows": [
	        { "aa": 10, "bb", 20, "cc": 30 },
	        { "aa": 11, "bb", 21, "cc": 31 }
	    ]
	},
	{
	    "rows": [
	        { "dd": 40, "ee", 50 }
	    ]
	}
]

Tip 서버 응답 형식이 다를 경우, cbResult 및 cbBaseResult 콜백을 사용하여 데이터를 변환할 수 있습니다.

서버 응답 데이터가 다수의 엔티티로 구성되어 있을 경우, 출력 뷰(MetaView)는 생성된 출력 뷰의 개수만큼 데이터를 가져옵니다.

참조 : 흐름 제어 > 응답 처리 콜백, JSON 스키마 가이드 > ENTITY 모드

모든 데이터 가져오기 (outOpt = 'ALL')#

서버의 모든 데이터를 출력 뷰(MetaView)에 매핑합니다.

js
const bm = new BindModel();

// 출력 옵션 'ALL'으로 명령 추가
bm.addCommand('cmd1', 'ALL');    

// 'output2' 추가
bm.cmd['cmd1'].newOutput();  

// 명령 실행
bm.cmd['cmd1'].execute();

// bm.columns.count == 5
// bm.columns['cmd1'].output.rows[0]['aa'] == 10
// bm.columns['cmd1'].output.rows[0]['bb'] == 20
// bm.columns['cmd1'].output.rows[0]['cc'] == 30
// bm.columns['cmd1'].output.rows[1]['aa'] == 11
// bm.columns['cmd1'].output.rows[1]['bb'] == 21
// bm.columns['cmd1'].output.rows[1]['cc'] == 31

// bm.columns['cmd1'].output2.rows[0]['dd'] == 40
// bm.columns['cmd1'].output2.rows[0]['ee'] == 50
  • 모든 데이터를 출력 뷰에 가져옵니다.

Tip 서버 데이터를 가져올 때, 출력 뷰(MetaView)에 미리 컬럼 정의가 되어 있다면, 해당 정의를 그대로 사용합니다.

지정 데이터 가져오기 (outOpt ='PICK')#

서버에서 지정한 컬럼명을 가져와 출력 뷰에 매핑합니다.

js
const bm = new BindModel();

// 출력 옵션 'PICK'으로 명령 추가
bm.addCommand('cmd1', 'PICK');

// 'output2' 추가
bm.cmd['cmd1'].newOutput();

// 컬럼 추가 및 출력 뷰에 매핑
bm.cmd['cmd1'].addColumn('aa', 'output');
bm.cmd['cmd1'].addColumn('bb', 'output');
bm.cmd['cmd1'].addColumn('dd', 'output2');
bm.cmd['cmd1'].addColumn('ee', 'output2');

bm.cmd['cmd1'].execute();

// bm.columns.count == 4  ('aa', 'bb', 'dd', 'ee')
// bm.columns['cmd1'].output.rows[0]['aa'] == 10
// bm.columns['cmd1'].output.rows[0]['bb'] == 20
// bm.columns['cmd1'].output.rows[1]['aa'] == 11
// bm.columns['cmd1'].output.rows[1]['bb'] == 21

// bm.columns['cmd1'].output2.rows[0]['dd'] == 40
// bm.columns['cmd1'].output2.rows[0]['ee'] == 50
  • 지정된 컬럼명만 출력 뷰에 매핑합니다.
  • 각 출력 뷰의 컬럼 개수는 지정된 컬럼으로 제한됩니다.

지정 데이터 가져와서 컬럼 설정 (outOpt ='VIEW')#

서버에서 지정한 컬럼 데이터를 출력 뷰에 매핑하고, index 위치의 rows 데이터를 컬럼값으로 설정합니다.

js
const bm = new BindModel();

// 출력 옵션 'VIEW'으로 명령 추가
bm.addCommand('cmd1', 'VIEW');

// 'output2' 추가
bm.cmd['cmd1'].newOutput();  

// 컬럼 추가 및 출력 뷰에 매핑
bm.cmd['cmd1'].addColumn('aa', 'output');
bm.cmd['cmd1'].addColumn('bb', 'output');
bm.cmd['cmd1'].addColumn('dd', 'output2');
bm.cmd['cmd1'].addColumn('ee', 'output2');

bm.cmd['cmd1'].execute();

// bm.columns.count == 4 ('aa', 'bb', 'dd', 'ee')
// bm.columns['aa'].value == 10
// bm.columns['bb'].value == 20
// bm.columns['dd'].value == 40
// bm.columns['ee'].value == 50
  • 1단계 : 지정된 컬럼 데이터를 출력 뷰에 매핑합니다.
  • 2단계 : index 위치의 rows 데이터 값을 컬럼의 값(value)으로 설정합니다.

Tip

outputOption.index는 rows에서 설정할 위치를 의미하며, 기본값은 0입니다.

복수 출력 인덱스#

복수 출력 인덱스 설정하기#

명령(BindCommand) 객체의 outputOption.index 속성을 사용하여 출력 데이터를 가져올 인덱스를 배열 또는 단일 숫자로 지정할 수 있습니다.

Tip 인덱스 설정은 outputOption = 'VIEW' 인 경우에만 유효하며, 기본 인덱스 값은 0입니다.

ts
type OptionType = 'SEND' | 'VIEW' | 'ALL' | 'PICK'; // default 'SEND'
type SchemaType = 'AUTO' | 'DATA' | 'ENTITY';       // default 'AUTO'
type IndexType = number | number[]; // // default 0
type OutOptType = { option: OptionType, schema: SchemaType, index: IndexType }

type outputOption = OutOptType | OptionType | SchemaType | IndexType;
type outOpt = outputOption;   // outputOption의 별칭

명령(BindCommand)의 index 값을 배열 또는 숫자로 지정합니다.

js
bm.command['cmd1'].outputOption.index = [1, 2];
bm.command['cmd2'].outputOption.index = 1;
bm.command['cmd3'].outputOption = { index: [1, 2] };
bm.command['cmd4'].outOpt.index = [1, 2];
  • 'cmd1' 은 첫 번째 엔티티 index = 1, 두 번째 엔티티 index = 2
  • 'cmd2' 은 모든 엔티티 index = 1
  • 'cmd3' 은 첫 번째 엔티티 index = 1, 두 번째 엔티티 index = 2
  • 'cmd4' 은 첫 번째 엔티티 index = 1, 두 번째 엔티티 index = 2

복수 출력 인덱스 가져오기#

서버 응답 데이터가 여러 엔티티로 구성되어 있을 때, 각 엔티티에 대해 가져올 컬럼값 인덱스를 지정할 수 있습니다.

json
// SERVER DATA
[
	{
	    "rows": [
	        { "aa": 10, "bb", 20, "cc": 30 },
	        { "aa": 11, "bb", 21, "cc": 31 }
	    ]
	},
	{
	    "rows": [
	        { "dd": 40, "ee", 50 },
	        { "dd": 41, "ee", 51 },
	        { "dd": 42, "ee", 52 }
	    ]
	}
]

복수 엔티티에 대해 index 는 배열로 지정합니다.

Tip index 는 배열과 같이 0부터 시작합니다.

js
const bm = new BindModel();

bm.addCommand('cmd1', 'VIEW');

// 'output2' 추가
bm.cmd['cmd1'].newOutput();  

// 첫 번째 엔티티: index 1, 두 번째 엔티티: index 2
bm.cmd['cmd1'].outputOption.index = [1, 2];

// 컬럼 추가 및 출력 뷰 매핑
bm.cmd['cmd1'].addColumn('aa', 'output');
bm.cmd['cmd1'].addColumn('bb', 'output');
bm.cmd['cmd1'].addColumn('dd', 'output2');
bm.cmd['cmd1'].addColumn('ee', 'output2');

bm.cmd['cmd1'].execute();

// bm.columns.count == 4
// bm.columns['aa'].value == 11
// bm.columns['bb'].value == 21
// bm.columns['dd'].value == 42
// bm.columns['ee'].value == 52
  • 첫번째 엔티티에서 index = 1 의 rows 값을 가져옵니다.
  • 두번째 엔티티에서 index = 2 의 rows 값을 가져옵니다.

Tip 엔티티 개수보다 index 배열 길이가 작으면, 부족한 인덱스는 기본값 0으로 설정됩니다. 엔티티 개수보다 index 배열 길이가 크면, 초과된 값은 무시됩니다.

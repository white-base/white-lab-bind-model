API 레퍼런스05

MetaObject

객체 식별, 타입 확인, 직렬화를 위한 기본 API입니다.

한국어 문서약 10분

MetaObject 는 모델(BindModel)과 연관된 모든 클래스의 최상위 클래스 입니다.

구성 요소#

속성#

항목 설명
_guid 객체의 고유 식별자입니다.
_type 객체의 생성 함수를 참조합니다.

메소드#

항목 설명
equal() 두 객체를 비교하여 동일성을 확인합니다.
getTypes() 객체의 상속 계층 구조를 반환합니다.
instanceOf() 객체가 특정 클래스의 인스턴스인지 확인합니다.
getObject() 현재 객체를 직렬화된 객체로 반환합니다.
setObject() 직렬화된 객체를 현재 객체에 설정합니다.

주요 속성#

_guid#

객체의 고유 식별자 속성입니다.

ts
type _guid = string;

_guid 속성은 객체의 고유성을 보장하는 중요한 속성입니다. BindModel의 모든 객체는 _guid 값을 가지며, 객체 생성 시 자동으로 설정됩니다.

  • 이 값은 수동으로 수정하거나 변경할 수 없습니다.
js
// 객체 생성
const obj1 = new MetaObject();
const obj2 = new MetaObject();

console.log("Object 1 GUID:", obj1._guid); 
console.log("Object 2 GUID:", obj2._guid);

console.log("Are GUIDs unique? ", obj1._guid !== obj2._guid); // Out: true
  • obj1._guid와 obj2._guid를 비교하여 두 값이 서로 다른지 확인합니다.

_type#

객체의 생성 함수를 참조하는 속성입니다.

ts
type _type = Function;

_type 속성은 MetaObject 클래스를 상속한 모든 객체가 생성될 때 자동으로 설정되며, 객체의 클래스 또는 생성자를 가르킵니다.

js
// 객체 생성
const obj1 = new MetaTable('t1');
const obj2 = new MetaColumn('c1');

console.log(obj1._type === MetaTable);  // Out: true
console.log(obj2._type === MetaColumn); // Out: true
  • _type 속성은 MetaObject 을 상속한 객체의 생성자를 확인하는데 사용됩니다.
js
// MetaObject 자식 클래스 정의
class MyClass extends MetaObject {}

// 객체 생성
const metaObj = new MetaObject();
const myObj = new MyClass();

console.log(metaObj._type === MetaObject); // Out: true
console.log(myObj._type === MyClass);      // Out: true
  • MetaObject 클래스를 상속한 클래스에서 _type 을 통해 생성자를 확인할 수 있습니다.

주요 메소드#

equal()#

현재 객체와 지정된 객체가 동일하는 메서드입니다.

ts
declare function equal(target: MetaObject): boolean;
  • target: 비교할 대상 객체

equal() 메서드는 _guid 속성을 제외하고 객체가 동일한지 비교합니다.

js
// 객체 생성
const obj1 = new MetaObject();
const obj2 = new MetaObject();
const obj3 = {};

// equal() 메서드 사용
console.log(obj1.equal(obj2)); // Out: true
console.log(obj1.equal(obj3)); // Out: false
  • equal() 메서드 사용하여 객체가 동일한지 확인합니다.

getTypes()#

객체의 상속 계층 구조를 반환하는 메서드입니다.

ts
declare function getTypes() : Function[];
  • Array<Function>: 상속 계층의 함수 배열
    • 배열의 첫 번째 요소는 생성자 함수입니다.
    • 이후 요소는 상위 클래스 생성자 함수가 순서대로 포함됩니다.

getTypes() 메서드는 객체의 클래스의 상속 계층 구조를 배열로 반환합니다.

js
// 클래스 정의
class MyClass extends MetaObject {}

// 객체 생성
const obj = new MyClass();

console.log(obj.getTypes()); // Out: [MyClass, MetaObject]
  • 반환된 배열은 MyClass부터 시작하여 MetaObject 순으로 상속 계층 구조를 보여줍니다.

instanceOf()#

객체가 특정 클래스의 인스턴스인지 확인하는 메서드입니다.

ts
declare function instanceOf(target: object | string): boolean;
  • target: 클래스 생성자 함수 또는 클래스 이름(문자열)
  • 반환값 : 객체의 생성자 함수와 일치하거나, 상속 관계에 있는 경우 true를 반환합니다.

instanceOf() 메서드는 객체의 생성자 함수 또는 생성자 이름을 사용하여 인스턴스 여부를 검사합니다.

instanceof 연산자 같은 역활을 수행하지만 추가적으로 다음 기능을 제공합니다.

  • 인터페이스 타입 검사 : 정의된 인터페이스 타입을 함께 검사할 수 있습니다. (별도 제공 예정)
  • 느슨한 검사 지원 : 생성자 함수를 문자열로 검사하여 의존성 문제를 우회할 수 있습니다.

인스턴스 검사 예제

js
// 클래스 정의
class MyClass extends MetaObject { /* 클래스 정의 */}

// 객체 생성
const obj = new MyClass();
const meta = new MetaObject();

// 생성자 기반 타입 확인
console.log(obj.instanceOf(MetaObject));   // Out: true
console.log(obj.instanceOf(MyClass));      // Out: true
console.log(meta.instanceOf(MetaObject));  // Out: true
// 문자열 기반 타입 확인
console.log(obj.instanceOf('MetaObject'));   // Out: true
console.log(obj.instanceOf('MyClass'));      // Out: true
console.log(meta.instanceOf('MetaObject'));  // Out: true
  • instanceOf() 메소드를 사용해서 생성자 또는 생성자명으로 인스턴스 여부를 검사합니다.

정적 인터페이스 타입

ts
declare class MyClass {
  static _UNION: Function[];
}
// 또는
declare class MyClass {}
declare namespace MyClass {
  const _UNION: Function[];
}
  • _UNION 정적 배열 타입으로 인터페이스를 정의할 수 있습니다.

인터페이스 구현 검사 예제

js
// 인터페이스 정의
class IClassA {}
class IClassB {}

// 클래스 정의
class MyClass extends MetaObject {} 

// 인터페이스 구현 지정
MyClass._UNION = [IClassA, IClassB]; 

const obj = new MyClass();

console.log(obj.instanceOf(MyClass)); // Out: true
console.log(obj.instanceOf(IClassA)); // Out: true
console.log(obj.instanceOf(IClassB)); // Out: true
  • obj 객체가 MyClass의 인스턴스이거나, IClassA, IClassB 인터페이스를 구현했는지 검사합니다.

추후 인터페이스 사용 방법이 제공될 예정입니다.

getObject()#

현재 객체를 직렬화된 객체로 반환하는 메서드입니다.

ts
declare function getObject(
	vOpt?: number, 
	owned?: object | object[]
): object;
  • vOpt(선택) : 직렬화 옵션 (기본값 0)
    • 0: guid 참조 구조를 유지합니다 (_guid: 예, $ref: 예)
    • 1: guid 중복 구조로 출력합니다 (_guid: 예, $ref: 예)
    • 2: 비참조 구조로 출력합니다 (_guid: 아니오, $ref: 아니오).
  • owned(선택) : 소유 객체나 소유 객체 배열
    • 기본값은 빈 객체이며, 데이터 출력 시 소유 관계를 포함하거나 필터링할 때 사용됩니다.

getObject() 메서드는 현재 객체를 직렬화된 JSON 형식의 객체로 반환합니다. 이를 활용하여 객체의 내부 데이터를 시각화하거나 외부로 전달할 수 있습니다.

반환된 데이터는 객체의 현재 상태를 복사한 값이며, 원본 객체에 영향을 주지 않습니다.

js
// 객체 생성
const v1 = new MetaView('view1');
const v2 = new MetaView('view2');

// 객체 직렬화
const obj = v1.getObject();

// 객체 역직렬화
v2.setObject(obj);

console.log(v1._guid === v2._guid); // Out: false
console.log(v1.viewName);           // Out: 'view1'
console.log(v2.viewName);           // Out: 'view1'
  • v1 객체는 v2와 동일한 데이터를 갖지만, 고유 식별자(_guid)는 서로 다릅니다.

setObject()#

직렬화된 객체를 현재 객체에 설정하는 메서드입니다.

ts
declare function setObject(oGuid: object, origin?: object): void;
  • oGuid: 직렬화된 객체
    • 데이터로, 현재 객체에 설정할 속성과 값을 포함합니다.
  • origin(선택): 내부 컨텍스트 객체
    • 설정시 내부적으로 사용되면 추가적인 컨텍스트 정보를 설정할 수 있습니다.

setObject() 메서드는 getObject()를 통해 얻은 직렬화 객체를 사용하여 현재 객체를 설정합니다. 이 과정에서 기존에 설정된 데이터는 모두 삭제됩니다.

js
// 객체 생성
const v1 = new MetaView('view1');
const v2 = new MetaView('view2');

// 객체 직렬화
const obj = v1.getObject();

// 객체 역직렬화
v2.setObject(obj);

console.log(v1._guid === v2._guid); // Out: false
console.log(v1.viewName);           // Out: 'view1'
console.log(v2.viewName);           // Out: 'view1'
  • v1 객체는 v2와 동일한 데이터를 가지지만, 고유 식별자(_guid)는 다릅니다.

Util.implements() : 메소드에서는 대상 객체가 인터페이스를 구현하였으면, _inteface 속성이 추가 됩니다.

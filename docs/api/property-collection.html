API 레퍼런스05

PropertyCollection

키와 인덱스로 접근하는 컬렉션의 속성과 메서드를 확인합니다.

한국어 문서약 32분

  1. 모델(BindModel)의 컬렉션 관리 • command, fn, items, columns 의 컬렉션 속성에 사용됩니다.

  2. 명령(BindCommand)의 뷰 컬렉션 관리 • valid.columns, bind.columns, output.columns 속성에 사용됩니다.

  3. 엔티티 컬렉션 관리 • MetaTable과 MetaView의 columns 컬렉션으로 사용됩니다.

_owner 소유한 객체를 참조합니다.
_elemTypes 컬렉션에 포함될 수 있는 요소들의 타입을 제한합니다.
_list 컬렉션에 포함된 모든 요소를 저장하는 내부 배열입니다.
count 컬렉션의 요소 개수를 나타냅니다.

exists() 컬렉션에 특정 키가 존재하는지 확인합니다.
remove() 컬렉션에서 특정 요소를 제거합니다.
removeAt() 컬렉션에서 지정된 위치의 요소를 제거합니다.

indexToKey() 컬렉션에서 지정된 인덱스에 해당하는 요소의 키를 반환합니다.

주요 속성#

_owner#

소유한 객체를 참조하는 속성입니다.

ts
type _owner = Object | null;
  • Object: 현재 객체를 소유한 개체
  • null: 소유 개체가 없을 때 (기본값)

_owner 속성은 객체의 소유자를 참조하는 속성으로, 소유 관계를 정의하고 추적하는 데 사용됩니다.

js
class UserTable {
    constructor() {
        this.data = new PropertyCollection(this);
    }
}

// UserTable 객체 생성
const user = new UserTable();

// _owner가 올바르게 설정되었는지 확인
user.data._owner === user // true
  • 생성자를 통해서 _onwer속성이 설정됩니다.

_elemTypes#

컬렉션에 포함될 수 있는 요소들의 타입을 제한하는 속성입니다.

ts
type _elemTypes = any[];

_elemTypes 속성은 컬렉션에서 허용되는 데이터 유형을 정의하며, 특정 유형만 추가할 수 있습니다.

  • 값을 지정하지 않으면 모든 유형이 허용됩니다.

타입 관리 추후 정보가 제공될 예정입니다.

_list#

컬렉션에 포함된 모든 요소를 저장하는 내부 배열 속성입니다.

ts
declare const _list: any[];

_list 속성은 컬렉션 객체에서 데이터를 저장하는 핵심 속성으로, 요소의 추가, 제거, 검색을 담당하는 내부 배열입니다.

  • 직접 접근하기보다는 제공된 메서드를 통해 조작하는 것을 권장합니다.
js
const collection = new PropertyCollection();

// 요소 추가
collection.add('key1', 'item1');
collection.add('key2', 'item2');

console.log(collection._list); // Out: ['item1', 'item2']
  • add() 메소드로 요소를 추가하면 내부적으로 _list 에 저장됩니다.

count 또는 length#

컬렉션의 요소 개수를 나타내는 속성입니다.

별칭으로 length 참조 속성을 제공합니다.

ts
declare const count: number;

count는 컬렉션 객체에서 요소의 개수를 나타내는 읽기 전용 속성입니다.

js
const collection = new PropertyCollection();

// 요소 추가
collection.add('key1', 'item1');
collection.add('key2', 'item2');

console.log(collection.count);  // Out: 2
console.log(collection.length); // Out: 2
  • count속성과 length속성을 통해 현재 컬렉션의 요소 개수를 확인합니다.

주요 메소드#

add()#

컬렉션에 새로운 요소를 추가하는 메서드입니다.

ts
declare function add(
	key: string, 
	elem: any, 
	desc?: PropertyDescriptor
): number;
  • key: string: 추가할 요소의 고유 키
  • elem: any: 컬렉션에 추가할 요소
  • desc(선택): 속성을 설명하는 디스크립터
  • 반환값 : 추가한 요소의 인덱스

add() 메서드는 컬렉션에 새로운 요소를 추가하고, 고유 키를 기반으로 관리합니다.

  • 선택적으로 PropertyDescriptor를 사용하여 요소의 속성을 정의할 수 있습니다.
  • 중복된 키가 사용될 경우 예외가 발생합니다.
js
const collection = new PropertyCollection();

// 요소 추가
collection.add('key1', 'item1');
collection.add('key2', 'item2', { writable: true });

console.log(collection.count);   // Out: 2
console.log(collection.length);  // Out: 2
console.log(collection.contains('key1')); // Out: true
  • add() 메서드를 사용하여 컬렉션에 고유 키와 함께 새로운 요소를 추가합니다.

clear()#

컬렉션의 모든 요소를 제거하는 메서드입니다.

ts
declare function clear(): void;

clear() 메서드는 컬렉션의 모든 데이터를 삭제하여 초기화합니다.

js
const collection = new PropertyCollection();

// 요소 추가
collection.add('key1', 'item1');
console.log(collection.contains('key1'));  // Out: true

// 컬렉션 초기화
collection.clear();
console.log(collection.contains('key1')); // Out: false
  • 컬렉션의 모든 데이터를 제거하여 비어 있는 상태로 만듭니다.

exist()#

컬렉션에 특정 키가 존재하는지 확인하는 메서드입니다.

ts
declare function exist(key: string): boolean;
  • key: 확인할 키
  • 반환값 : 키가 존재하면 true, 존재하지 않으면 false를 반환합니다.

exist() 메서드는 컬렉션에 특정 키가 포함되어 있는지 boolean 값으로 나타냅니다.

js
const collection = new PropertyCollection();

// 요소 추가
collection.add('key1', 'item1');

console.log(collection.exist('key1')); // Out: true
console.log(collection.exist('key3')); // Out: false
  • exist() 메서드를 사용하여 특정 요소가 컬렉션에 포함되어 있는지 확인합니다.

remove()#

컬렉션에서 특정 요소를 제거하는 메서드입니다.

ts
declare function remove(elem: any): number;
  • elem: 제거할 요소
  • 반환값 : 제거된 요소의 인덱스 반환하고, 요소가 존재하지 않을 경우 -1을 반환합니다.

remove() 메서드는 컬렉션에서 특정 요소를 제거하고, 제거된 요소의 인덱스를 반환합니다.

  • 요소가 존재하지 않으면 -1을 반환하며, 첫 번째로 매칭된 요소만 제거합니다.
js
const collection = new PropertyCollection();

// 요소 추가
collection.add('key1', 'item1');
collection.add('key2', 'item2');

// 요소 제거
console.log(collection.remove('item1')); // Out: 0  (인덱스 번호)
console.log(collection.remove('item3')); // Out: -1 (요소가 존재하지 않음)

// 요소 확인
console.log(collection.exist('key1')); // Out: false
console.log(collection.exist('key2')); // Out: true
  • remove() 메서드는 지정된 요소를 기준으로 제거를 수행하며, 제거된 요소의 인덱스를 반환합니다.

removeAt()#

컬렉션에서 지정된 위치의 요소를 제거하는 메서드입니다.

ts
declare function removeAt(pos: number): boolean;
  • pos: 제거할 요소의 위치(인덱스)
  • 반환값 : 요소 제거에 성공하면 true, 인덱스가 유효하지 않으면 false를 반환합니다.

removeAt() 메서드는 컬렉션에서 지정된 위치의 요소를 제거합니다.

js
const collection = new PropertyCollection();

// 요소 추가
collection.add('key1', 'item1');
collection.add('key2', 'item2');

// 인덱스로 요소 제거
console.log(collection.removeAt(0)); // Out: true
console.log(collection.removeAt(2)); // Out: false (유효하지 않은 인덱스)

// 요소 확인
console.log(collection.exist('key1')); // Out: false
console.log(collection.exist('key2')); // Out: true
  • removeAt() 메서드를 호출하여 지정된 인덱스의 요소를 제거합니다.

contains()#

컬렉션에 특정 요소가 포함되어 있는지 확인하는 메서드입니다.

ts
declare function contains(elem): boolean;
  • elem: 확인할 요소
  • 반환값 : 요소가 컬렉션에 포함되어 있으면 true, 그렇지 않으면 false를 반환합니다.

contains() 메서드는 컬렉션에 특정 요소가 포함되어 있는지 여부를 확인합니다.

js
const collection = new PropertyCollection();

// 요소 추가
collection.add('key1', 'item1');
collection.add('key2', 'item2');

// 요소 포함 여부 확인
console.log(collection.contains('item1')); // Out: true
console.log(collection.contains('item3')); // Out: false
  • contains() 메서드를 호출하여 특정 요소가 컬렉션에 포함되어 있는지 확인합니다.

indexOf()#

컬렉션에서 특정 요소의 인덱스를 반환하는 메서드입니다.

ts
declare function indexOf(elem: any): number;
  • elem: 인덱스를 찾을 요소
  • 반환값 : 요소의 인덱스를 반환하고, 요소가 존재하지 않을 경우 -1을 반환합니다.

indexOf() 메서드는 컬렉션에서 특정 요소의 인덱스를 검색하는 데 사용됩니다.

js
const collection = new PropertyCollection();

// 요소 추가
collection.add('key1', 'item1');
collection.add('key2', 'item2');

// 요소 인덱스 확인
console.log(collection.indexOf('item1')); // Out: 0
console.log(collection.indexOf('item2')); // Out: 1
console.log(collection.indexOf('item3')); // Out: -1
  • indexOf() 메서드를 호출하여 특정 요소의 인덱스를 검색합니다.

keyToIndex()#

컬렉션에서 특정 키에 해당하는 인덱스를 반환하는 메서드입니다.

ts
declare function keyToIndex(key: string): number;
  • key: 인덱스를 찾을 요소의 키
  • 반환값 : 키의 인덱스를 반환하고, 키가 없으면 -1을 반환합니다.

keyToIndex() 메서드는 컬렉션에서 특정 키에 매핑된 요소의 인덱스를 검색합니다.

js
const collection = new PropertyCollection();

// 요소 추가
collection.add('key1', 'item1');
collection.add('key2', 'item2');

// 키의 인덱스 검색
console.log(collection.keyToIndex('key1')); // Out: 0
console.log(collection.keyToIndex('key2')); // Out: 1
console.log(collection.keyToIndex('key3')); // Out: -1
  • keyToIndex() 메서드를 호출하여 특정 키에 매핑된 요소의 인덱스를 검색합니다.

indexToKey()#

컬렉션에서 지정된 인덱스에 해당하는 요소의 키를 반환하는 메서드입니다.

ts
declare function indexToKey(idx: number): string | undefined;
  • index: 키를 검색할 요소의 인덱스
  • 반환값 : 인덱스에 해당하는 키를 반환하며, 유효하지 않은 인덱스일 경우 undefined를 반환합니다.

indexToKey() 메서드는 컬렉션에서 지정된 인덱스의 요소에 매핑된 키를 반환합니다.

js
const collection = new PropertyCollection();

// 요소 추가
collection.add('key1', 'item1');
collection.add('key2', 'item2');

// 인덱스를 기반으로 키 검색
console.log(collection.indexToKey(0)); // Out: 'key1'
console.log(collection.indexToKey(1)); // Out: 'key2'
console.log(collection.indexToKey(2)); // Out: undefined (유효하지 않은 인덱스)
  • indexToKey() 메서드를 호출하여 특정 인덱스에 매핑된 키를 반환합니다.

주요 고차 함수#

map()#

컬렉션의 각 요소에 함수를 적용하여 새로운 배열을 반환하는 고차 함수입니다.

ts
declare function map<T, U>(
	callbackfn: (value: T, index: number, key: string, array: T[]) => U, 
	thisArg?: any
): U[];
  • callbackfn: 새로운 배열 요소를 생성하는 함수
    • value: 처리할 현재 요소
    • index: 처리할 현재 요소의 인덱스
    • key: 처리할 현재 요소의 키
    • array: map()을 호출한 배열
  • thisArg(선택): callback을 실행할 때 this로 사용되는 값
  • U[]: 콜백 함수의 결과를 포함한 새로운 배열을 반환합니다.

map() 함수는 컬렉션의 모든 요소에 대해 순차적으로 주어진 콜백 함수를 실행하고, 각 실행 결과를 새로운 배열로 반환합니다.

  • 원본 컬렉션은 변경되지 않으며, 데이터 변환이나 계산 작업에 유용합니다.
js
const collection = new PropertyCollection();

// 요소 추가
collection.add('key1', 1);
collection.add('key2', 2);

// 요소 값을 두 배로 변환
const doubledValues = collection.map((value) => value * 2);
console.log(doubledValues); // Out: [2, 4]
  • map() 함수를 호출하여 각 요소의 값을 두 배로 변환하는 콜백을 전달합니다.

filter()#

조건을 만족하는 요소만 포함하는 새로운 배열을 반환하는 고차 함수입니다.

ts
declare function filter<T>(
    callbackfn: (value: T, index: number, key: string, array: T[]) => boolean, 
    thisArg?: any
): T[];
  • callbackfn: 조건을 검사하는 함수
    • value: 처리할 현재 요소
    • index: 처리할 현재 요소의 인덱스
    • key: 처리할 현재 요소의 키
    • array: filter()를 호출한 배열
  • thisArg(선택): callback을 실행할 때 this로 사용되는 값
  • T[]: 조건을 만족하는 요소들로 구성된 새로운 배열.

filter() 함수는 컬렉션에서 주어진 조건을 만족하는 요소만 추출하여 새로운 배열을 반환합니다.

  • 원본 컬렉션은 변경되지 않으며, 데이터 필터링 작업에 유용합니다.
js
const collection = new PropertyCollection();

// 요소 추가
collection.add('key1', 1);
collection.add('key2', 2);
collection.add('key3', 3);

// 짝수 값만 필터링
const evenValues = collection.filter((value) => value % 2 === 0);
console.log(evenValues); // Out: [2]
  • filter() 함수를 호출하여 짝수 조건에 만족하는 요소만 추출하여 반환합니다.

reduce()#

컬렉션의 모든 요소를 순회하며 누적 값을 계산하는 고차 함수입니다.

ts
declare function reduce<T, U>(
    callbackfn: (
        previousValue: U, 
        currentValue: T, 
        currentIndex: number, 
        currentKey: string,
        array: T[]
    ) => U, 
    initialValue: U
): U;
  • callbackfn: 누적 값을 계산하는 함수
    • previousValue: 이전 콜백 실행의 반환값 또는 초기값
    • currentValue: 처리할 현재 요소
    • currentIndex: 처리할 현재 요소의 인덱스
    • currentKey: 처리할 현재 요소의 키
    • array: reduce()를 호출한 배열
  • initialValue: 누적 연산의 초기값
  • T: 배열 요소 타입
  • U: 최종 계산 결과

reduce() 함수는 컬렉션의 모든 요소를 순회하며, 주어진 콜백 함수를 사용해 누적 결과를 계산합니다.

초기값이 설정되면 첫 번째 콜백 호출 시 previousValue로 사용되며, 설정하지 않으면 컬렉션의 첫 번째 요소가 초기값이 됩니다.

js
const collection = new PropertyCollection();

// 요소 추가
collection.add('key1', 1);
collection.add('key2', 2);
collection.add('key3', 3);

// 모든 값을 합산
const sum = collection.reduce((acc, value) => acc + value, 0);
console.log(sum); // Out: 6
  • reduce() 함수를 호출하여 각 요소를 순회하며 누적 값을 계산하는 콜백을 전달합니다.

find()#

컬렉션에서 조건을 만족하는 첫 번째 요소를 반환하는 고차 함수입니다.

ts
declare function find<T>(
    callbackfn: (value: T, index: number, key: string, array: T[]) => boolean, 
    thisArg?: any
): T | undefined;
  • callbackfn: 조건을 검사하는 함수
    • value: 처리할 현재 요소
    • index: 처리할 현재 요소의 인덱스
    • key: 처리할 현재 요소의 키
    • array: find()를 호출한 배열
  • thisArg(선택): callback을 실행할 때 this로 사용되는 값
  • 반환값 : 조건을 만족하는 첫 번째 요소를 반환하며, 조건에 맞는 요소가 없으면 undefined를 반환합니다.

find() 함수는 컬렉션에서 조건을 만족하는 첫 번째 요소를 반환합니다.

Tip: 데이터 검색이나 특정 조건에 부합하는 값을 찾는 데 유용합니다.

js
const collection = new PropertyCollection();

collection.add('key3', 30);

// 조건을 만족하는 첫 번째 요소 검색

  • find() 함수를 호출하여 값이 15보다 큰 첫 번째 요소를 찾아 반환합니다.

forEach#

컬렉션의 각 요소에 대해 주어진 작업을 수행하는 고차 함수입니다.

ts
declare function forEach<T>(
    callbackfn: (value: T, index: number, key: string, array: T[]) => void, 
    thisArg?: any
): void;
  • callbackfn: 각 요소에 대해 호출되는 함수
    • value: 처리할 현재 요소
    • index: 처리할 현재 요소의 인덱스
    • key: 처리할 현재 요소의 키
    • array: forEach()를 호출한 배열
  • thisArg(선택): callback을 실행할 때 this로 사용되는 값

forEach() 함수는 컬렉션의 각 요소에 대해 주어진 콜백 함수를 실행합니다. 이 함수는 반환값이 없으며 원본 컬렉션은 변경되지 않습니다.

js
const collection = new PropertyCollection();

// 요소 추가
collection.add('key1', 10);
collection.add('key2', 20);
collection.add('key3', 30);

// 각 요소 출력
collection.forEach((value, index) => {
    console.log(`인덱스 ${index}, 키 "${this.indexToKey(index)}", 값 ${value}`);
});
// Out:
// '인덱스 0, 키 "key1", 값 10'
// '인덱스 1, 키 "key2", 값 20'
// '인덱스 2, 키 "key3", 값 30'
  • forEach 함수를 호출하여 각 요소와 해당 인덱스를 출력합니다.

some()#

조건을 만족하는 요소가 하나라도 있으면 true를 반환하는 고차 함수입니다.

ts
type callbackFn = (value: any, index: number, key: string, array: this) => any;
type some = (callbackFn, thisArg?: any) => boolean;
  • callbackfn: 조건을 검사하는 함수
    • value: 처리할 현재 요소
    • index: 처리할 현재 요소의 인덱스
    • key: 처리할 현재 요소의 키
    • array: some()을 호출한 배열
  • thisArg(선택): callback을 실행할 때 this로 사용되는 값
  • 반환값 : 조건을 만족하는 요소가 하나라도 있으면 true, 그렇지 않으면 false를 반환합니다.

some() 함수는 컬렉션에서 조건을 만족하는 요소가 하나라도 있으면 순회를 중단하고 true를 반환합니다.

js
const collection = new PropertyCollection();

collection.add('key2', 20);
collection.add('key3', 30);

console.log(collection.some(item => item > 25)); // Out: true
  • some() 함수는 첫 번째로 조건을 만족하는 요소를 찾으면 true를 반환하고 즉시 종료합니다.

onAdd#

ts
type onAdd = (elem: any, idx: number, _this: object) => void;
  • elem: 추가하려는 요소
  • idx: 추가되는 요소의 인덱스
  • _this: 이벤트를 호출한 객체

onAdd 는 컬렉션에 요소가 추가되기 전에 실행되는 이벤트로, 요소 추가 전에 유효성 검사나 기타 사전 작업을 수행하는 데 활용됩니다.

  • 콜백 함수에서 false를 반환하면 해당 요소의 추가와 이벤트 처리가 중단됩니다.

Tip : 이벤트 속성에 콜백함수를 설정하면, 기존 이벤트는 그대로 유지되며 새 이벤트가 추가됩니다.

js
const collection = new PropertyCollection();

// onAdd 이벤트 설정

    if (typeof elem !== "string") {
        console.log(`인덱스 ${idx}: 문자열만 추가 가능합니다.`);
        return false;
    }
    console.log(`인덱스 ${idx}: 추가된 요소는 '${elem}'입니다.`);
};

// 요소 추가
collection.add('key1', "Item"); // Out: '인덱스 0: 추가된 요소는 'Item'입니다.'
collection.add('key2', 123);    // Out: '인덱스 1: 문자열만 추가 가능합니다.'

console.log(collection.count); // Out: 1
  • 요소 추가시 요소 타입에 따라 콘솔에 로그를 출력합니다.
